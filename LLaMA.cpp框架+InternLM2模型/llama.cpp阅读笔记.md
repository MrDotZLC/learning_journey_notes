# 〇、环境准备
1. 环境：
	1. 系统：linux/wsl2
	2. IDE：vscode
	3. llama.cpp仓库：https://github.com/ggml-org/llama.cpp
2. 构建
	1. 删除预设文件：项目根目录/CMakePresets.json
	2. 关闭预设模式：vscode-settings-Use C Make Presets-never
	3. 打开CUDA配置：
	4. 设置build目标
	5. 以debug方式build llama-simple子项目
