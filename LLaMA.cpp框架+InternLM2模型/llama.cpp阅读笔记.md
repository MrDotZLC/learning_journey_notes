## 〇、环境准备
1. 环境：
	1. 系统：linux/wsl2
	2. IDE：vscode
	3. llama.cpp仓库：https://github.com/ggml-org/llama.cpp
2. 构建
	1. 删除预设文件：项目根目录/CMakePresets.json
	2. 关闭预设模式：vscode-settings-Use C Make Presets-never
	3. 打开CUDA配置：
	4. 设置build目标
	5. 以debug方式build llama-simple子项目

                                    │

                    ▼                               ▼
        ┌───────────────────────┐       ┌───────────────────────┐

        │  - 加载权重张量        │       │  - 设置计算流          │
        │  - 加载分词器词汇表    │       │  - 编译 Kernel         │
        └───────────┬───────────┘       └───────────┬───────────┘
                    │                               │
                    └───────────────┬───────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  创建 llama_context (上下文)   │
                    │  - 分配 KV Cache 空间          │
                    │  - 设置 n_ctx, n_batch 等参数  │
                    └───────────────┬───────────────┘
                                    │
┌───────────────────────────────────┴─────────────────────────────────────┐
│                          阶段二：输入处理                                │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  输入 Prompt (自然语言文本)    │
                    └───────────────┬───────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  分词 (Tokenization)           │
                    │  - 文本 -> Token IDs 序列      │
                    │  - 添加 BOS/EOS 特殊 token     │
                    └───────────────┬───────────────┘
                                    │
┌───────────────────────────────────┴─────────────────────────────────────┐
│                    阶段三：预填充 (Prefill)                              │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  构建计算图 (llama_build_graph)│

                    │  - 输出层 LM Head              │
                    └───────────────┬───────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  执行 llama_decode             │
                    │  - 并行处理所有 Prompt Token   │
                    │  - 计算并写入 KV Cache         │
                    │  - 输出最后一个 Token 的 Logits│
                    └───────────────┬───────────────┘
                                    │

                    │  - 温度 / Top-K / Top-P        │
                    │  - 从 Logits 选出下一个 Token  │
                    └───────────────┬───────────────┘
                                    ▼
                    ┌───────────────────────────────┐

                    │  - 遇到 EOS？                  │

                            │ 否            │ 是
                            ▼               │
            ┌───────────────────────────────┐ │
            │  将新 Token 追加到序列中       │ │
            └───────────────┬───────────────┘ │

            ┌───────────────────────────────┐ │
            │  执行 llama_decode            │ │
            │  - 仅处理新 Token             │ │
            │  - 读取历史 KV Cache          │ │
            │  - 更新 KV Cache              │ │
            │  - 输出新 Logits              │ │

                            │                 │
                            └─────────┐       │
                                      │       │
                                      ▼       ▼

└─────────────────────────────────────┬───────────────────────────────────┘
                                      ▼
                    ┌───────────────────────────────┐
                    │  反分词 (Detokenization)       │
                    │  - Token IDs -> 文本片段       │
                    │  - 缓冲拼接，处理多字节字符    │
                    └───────────────┬───────────────┘
                                    ▼
                    ┌───────────────────────────────┐
                    │  流式输出 / 返回完整文本       │
                    └───────────────────────────────┘
