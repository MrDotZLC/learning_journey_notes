# 一、量化（Quantization）的本质
量化是一个**有损映射（lossy mapping）**过程：
> **连续空间 / 高精度数值 → 离散空间 / 低比特数值**
 关键是：  
	**如何设计映射规则，使误差最小、效率最高、硬件可执行。**
---
# 二、核心数学概念
量化的核心公式是**仿射变换（Affine Mapping）**。对于一个浮点张量 $x$，其量化过程可以表示为：
 $$x_q = \text{round}\left(\frac{x}{S} + Z\right)$$
 - **$S$ (Scale) 缩放因子：** 决定了量化的步长。
	S 大 → 范围大但精度粗
	S 小 → 精度高但易溢出
- **$Z$ (Zero-point) 零点：** 保证浮点数中的 $0$ 能精确对应到整数空间。
	非对称量化中，浮点数据通常不是对称分布（如ReLU激活），Z 作为**偏移量**避免大量浪费。
- **反量化（Dequantization）：** 计算时还原为 $\hat{x} = S(x_q - Z)$。
---
# 三、截断（Clipping）
在神经网络中，激活或权重可能有极端值：
- 激活：ReLU 输出可能出现非常大的数值
- 权重：训练过程中可能存在 outlier
- 直接映射到 INT8 或 INT4 时，这些极端值会拉大 scale，降低整体精度

**直观理解**：如果一两个大值决定了整个 scale，其他 99% 的值可能只能用很粗的整数表示。
## 2.1 截断方法
### 2.1.1 Min-Max 截断
- 使用张量的最小值和最大值作为量化范围
- 简单，但极端值会影响整体精度
$$x_{min} = \min(x) , \quad x_{max} = \max(x)$$
### 2.1.2 Percentile 截断
- 忽略极少数异常值
- 常用 99% 或 99.9% percentile
- 更稳定，保留大部分分布信息

$$x_{min} = \text{Percentile}(x, 0.1\%), \quad x_{max} = \text{Percentile}(x, 99.9\%)$$
### 2.1.3 KL 散度截断
KL 散度截断是**后训练量化（PTQ, Post-Training Quantization）** 中的一种高级截断方法，通过最小化原始数据分布与量化后数据分布的差异，确定激活或权重的截断范围。
#### 2.1.3.1 背景
在激活量化中：
- 激活值分布通常呈 **长尾** 或 **非对称分布**
- 直接使用 **Min-Max 截断** 会被极端值拉大 scale，导致大部分常用值表示精度下降
- Percentile 截断忽略极端值，但无法保证量化后信息损失最小
#### 2.1.3.2 KL 散度定义
KL 散度提供了一种**概率分布差异的衡量方法**，用于寻找最优截断阈值。
KL 散度衡量两个概率分布 P 和 Q 的差异：
$$D_{KL}(P || Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)}$$
- P：原始浮点值的概率分布（通常通过直方图估计）
- Q：量化后的概率分布（量化到有限整数表示后再重建概率分布）
> KL 散度越小，表示量化后分布越接近原始分布，信息损失越小。
#### 2.1.3.3 KL 截断算法流程（以激活为例）
假设我们量化到 INT8（256 bins），流程如下：
- Step 1：统计原始分布
	- 将浮点激活值放入直方图，得到概率分布 P
	- 直方图 bin 数较大（例如 2048 bins）
- Step 2：选择候选截断阈值
	- 从小到大遍历不同的最大值 xmaxx_{max}xmax​
	- 将极端值截断到 xmaxx_{max}xmax​
- Step 3：模拟量化
	- 将截断后的范围映射到 INT8 的整数范围（0~255）
	- 将整数映射回浮点，得到量化后的分布 QQQ
- Step 4：计算 KL 散度
$$D_{KL}(P||Q) = \sum_{i} P(i) \log \frac{P(i)}{Q(i)}$$
- Step 5：选择最优阈值
	- 选择使 $D_{KL}(P||Q)$ 最小的 $x_{max}$
	- 该阈值即为量化截断点
> 	如果激活是非对称分布，还可以同时搜索 $x_{min}$​（下限）。
#### 2.1.3.4 数学直观理解
KL 散度截断本质是在解决一个优化问题：
$$x_{max}^* = \arg\min_{x_{max}} D_{KL}(P_{clip(x_{max})} || Q_{quantized(x_{max})})$$
- $P_{clip(x_{max})}$：截断后的原始分布
- $Q_{quantized(x_{max})}$：量化重建分布
> 核心目标：选择截断阈值，使量化后信息损失最小化，而不仅仅是覆盖全量程或去除极端值。
#### 2.1.3.5 工程实践
- **优点**：
    - 自动找到最佳截断阈值
    - 对非对称、长尾激活分布效果好
    - PTQ 中精度通常高于 Min-Max / Percentile
- **缺点**：
    - 计算复杂（需要多次直方图量化和 KL 计算）
    - 适合静态量化（校准数据集有限）
    - 对极低比特（INT4）可能仍需结合其他方法
- **应用场景**：
    - Transformer 激活量化
    - ResNet、MobileNet 后训练量化
    - 大模型 PTQ（如 LLM 激活量化）

# 三、舍入（Rounding）
量化过程中，有 Round 过程，使得反量化存在舍入误差。
## 3.1 常见舍入方法
### 3.1.1 Round-to-nearest（四舍五入）
- 误差范围 [−0.5s,+0.5s]
- 优点：简单、硬件易实现
- 缺点：累积误差在深层网络中可能偏移输出
### 3.1.2 Stochastic Rounding（随机舍入）
- 根据浮点数与上下邻近整数的距离，以概率选择舍入方向：
$$q = \begin{cases} \lfloor x \rfloor, & p = 1 - (x - \lfloor x \rfloor) \\ \lceil x \rceil, & p = x - \lfloor x \rfloor \end{cases}$$
- 优点：
    - 可以降低量化偏置
    - 对低比特量化（INT4 / INT2）尤其有效
- 缺点：
    - 实现复杂，需要随机数生成
### 3.1.3 Floor / Ceil
- Floor：向下取整 → 系统性偏小
- Ceil：向上取整 → 系统性偏大
- 通常在特定硬件或量化要求中使用，但容易产生偏差
## 3.2 工程实践
1. **权重量化**
    - 权重分布相对稳定，累积误差可控
    - 常用 **Round-to-nearest**
2. **激活量化**
    - 分布动态且非对称
    - 可以使用 **Stochastic Rounding 舍入**降低偏置
3. **低比特量化**
    - INT4 / INT2 中 Round-to-nearest 会导致严重误差
    - **Stochastic 舍入** 能显著提升稳定性
4. **硬件实现**
    - 大部分 GPU/CPU INT8 计算使用 Round-to-nearest
    - **Stochastic 舍入** 在软件模拟或定制硬件中实现

# 四、量化误差（Quantization Error）
量化不可避免会引入误差，通常可分为四类：
## 1. 舍入误差（Rounding Error）
### 来源
- 浮点数映射到离散整数时，需要舍入：
$$q = \text{round}(x/s + z)$$
 - 例如 FP32 → INT8 时，每个浮点数只能选择最接近的整数表示。
 ### 特性
 - 均值通常接近 0，但可能累积
 - 对低比特量化（INT4/INT2）影响大
 - 在深层网络中可能导致输出偏移
 ### 解决方法
 - 使用 **stochastic rounding**（随机舍入）降低偏置
 - 使用 **higher bit scale** 做累积
## 2. 截断误差（Clipping Error）
### 来源
 - 当数据超出量化表示范围时，必须截断：
$$x_{clip} = \text{clip}(x, x_{\min}, x_{\max})$$
 - 典型场景：激活值或权重中存在异常大值（outlier）
### 特性
 - 错误集中在极端值上
 - 损失信息，但对整体精度影响可控
 - 对非对称分布数据敏感
### 解决方法
 - **Percentile Clipping**：忽略极少数异常值
 - **KL Divergence 方法**：选择截断阈值最小化信息损失
## 3. 累积误差（Accumulation Error）
### 来源
 - 在深层网络中，每层量化误差会向后传播
 - 矩阵乘法或卷积中累加多个量化值时，误差叠加：
$$ \epsilon_{total} = \sum_i \epsilon_i$$
### 特性
 - 深层网络容易出现激活漂移（activation drift）
 - Transformer 或 ResNet 等深网络尤其敏感
 - 对最终输出 logits 可能产生显著偏移
### 解决方法
 - 保留 **bias 或累加结果为高精度（INT32 / FP32）**
 - 使用 **per-channel 量化** 减少误差差异
 - 激活校准（activation calibration）在部署时校正
## 4. 偏置误差（Bias Error / Distribution Shift）
### 来源
 - 数据分布或量化零点选择不当
 - 非对称量化中 zero-point 不匹配
 - 激活分布与训练数据分布不同（测试时 shift）
### 特性
 - 导致量化后输出系统性偏移
 - 对精度敏感层（如 Softmax / LayerNorm）影响大
 - 不是随机噪声，而是偏向一侧
### 解决方法
 - 使用 **非对称量化**，调整 zero-point
 - 激活范围动态调整（动态量化 / calibration）
 - 对关键层保持高精度
