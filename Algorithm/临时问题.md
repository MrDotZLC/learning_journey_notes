1. 传入并修改裸指针，为什么要传入指针地址，即T**？
   答：C语言参数传递是**值传递**，T\*仅代表T指针的地址值，故函数会创建一个值副本，没有修改传入指针。如果要修改函数外的变量，需要传入T\*\*或智能指针引用
   
2. struct和class的区别
   答：**struct** 和 **class** 唯一的语言层面区别是：
	- **struct** 默认成员和继承是 `public`。
	- **class** 默认成员和继承是 `private`。

3. 原始数组、栈和堆的区别？
   答：

| 特性 / 容器类型       | 原始数组 (`int a[3]`) | `std::array<int, 3>` | `std::vector<int>` |
| --------------- | ----------------- | -------------------- | ------------------ |
| **大小是否固定**      | 是                 | 是                    | 否，动态大小             |
| **是否支持动态扩容**    | 否                 | 否                    | 是                  |
| **是否支持赋值/拷贝**   | 否                 | 是                    | 是                  |
| **支持 STL 容器接口** | 否                 | 是                    | 是                  |
| **支持迭代器**       | 否                 | 是                    | 是                  |
| **访问越界检查**      | 无，易出错             | 有（`.at()` 抛异常）       | 有（`.at()` 抛异常）     |
| **内存分配位置**      | 栈上（或静态区）          | 栈上                   | 堆上                 |
| **自动管理内存**      | 否                 | 是                    | 是                  |
| **生命周期管理**      | 由作用域决定，无构造析构      | 由作用域决定，带构造析构         | 由对象管理，带构造析构        |
| **适用场景**        | 极限性能、C 兼容         | 固定大小、安全、STL 兼容       | 动态大小、灵活增删元素        |
| **性能开销**        | 最低，无封装            | 低，轻量封装               | 较高，动态内存分配          |
| **类型安全**        | 差                 | 高                    | 高                  |
| **易用性**         | 低，需要手动管理          | 高，易用                 | 很高，功能强大            |
