# 2 数组（Array）
![[Pasted image 20250711022215.png]]

## 一、基础概念
1. int arr\[3\] = {10, 20, 30};
2. 数组是存放在连续内存空间上的相同类型数据的集合。
3. 数组下标都是从0开始的。
4. 数组内存空间的地址是连续的，增删可能会移动其他元素。
5. 数组元素只能覆盖，不能删！
6. 不能释放单一元素，只能全部释放

## 二、数组的存储
1. 原始二维数组是一维连续存储
2. `array`本质上就是一个封装了原始数组的结构体，不涉及动态内存分配，本身是连续存储的，其二维数组也是一维连续存储
3. `vector`的每一行独立存储，其二维数组非连续
4. `int**` 动态二维指针，不连续，每一行指向单独分配的数组，位置随机
5. `std::vector<std::array<int, 4>>`中每个`array`是连续的，整体也是连续

## 三、数组为什么不能释放单个元素？
- 原因 1：连续内存 + 统一分配，
  数组的所有元素是一次性整体分配的（无论在栈还是堆上）。
  操作系统或运行时不会允许你释放这片内存的一部分。
- 原因 **2**：释放机制只认“起始地址”
  `free(ptr)` 只能用于释放当初 `malloc` 返回的那个原始地址。
  指向数组中间某个元素的地址是非法释放行为。

## 四、释放部分内容的替代方法
1. 用结构记录“有效元素”范围
```
int* arr = malloc(100 * sizeof(int));
int size = 100;
int valid_size = 60;  // 实际只用前 60 个元素
```
2. 拆成多个小块
```
int* blocks[10];
for (int i = 0; i < 10; ++i)
    blocks[i] = malloc(10 * sizeof(int));

// 想释放第5块
free(blocks[5]);
```

| 特性     | 栈（Stack）    | 堆（Heap）             |
| ------ | ----------- | ------------------- |
| 分配方式   | 编译器自动分配     | 程序员手动分配（malloc/new） |
| 释放方式   | 自动释放（函数结束时） | 手动释放（free/delete）   |
| 分配速度   | 非常快         | 相对较慢                |

| 生命周期   | 与作用域绑定      | 控制权在程序员             |
| 可否动态扩展 | ❌ 不行        | ✅ 可以动态申请更大空间        |



# 3 链表（Linked List）
## 基础概念
一种通过指针串联在一起的线性结构，每一个节点由两部分组成，一个是数据域一个是指针域（存放指向下一个节点的指针），最后一个节点的指针域指向null（空指针的意思）。

```
// 单链表
struct ListNode {
    int val;  // 节点上存储的元素
    ListNode *next;  // 指向下一个节点的指针
    ListNode(int x) : val(x), next(NULL) {}  // 节点的构造函数
};

ListNode* head = new ListNode();
ListNode* head = new ListNode(5);
```

类型：单链表、双链表、循环链表

## ==*数组VS链表==

| 对比项   | 数组           | 链表              |

| 内存连续性 | ✅ 是          | ❌ 否             |

| 扩容能力  | ❌ 需要重分配      | ✅ 不需重分配         |


# 4 哈希表（Hash Table）
## 基础概念
哈希表：根据关键码的值而直接进行访问的数据结构。数组就是以索引为关键码的哈希表。
哈希函数：将关键码转换为对应值的函数。
哈希碰撞：同一索引对应对个值，即哈希碰撞。解决办法：拉链法和线性探测法
## ==*常见的哈希结构*：数组、set、map==

| 集合                 | 底层实现 | 是否有序  | 数值是否可以重复 | 能否更改数值  | 查询效率     | 增删效率     |

| std::set           | 红黑树  | 有序    | 否        | 否       | O(log n) | O(log n) |

# 哈希类模板
```
#include <bits/stdc++.h>
using namespace std;

struct UniversalHash {
    // ---- 基础哈希混合函数（参考 boost::hash_combine）----
    template<typename T>
    static inline void hash_combine(size_t& seed, const T& v) {
        seed ^= std::hash<T>{}(v) + 0x9e3779b97f4a7c15ULL + (seed << 6) + (seed >> 2);
    }

    // ---- 通用哈希入口 ----
    template<typename T>
    size_t operator()(const T& v) const {
        return compute(v);
    }

private:
    // ---- 内部递归模板 ----

    // 1️⃣ 普通类型（内建类型、有 std::hash 的）
    template<typename T>
    static auto compute(const T& v) -> decltype(std::hash<T>{}(v)) {
        return std::hash<T>{}(v);
    }

    // 2️⃣ pair 类型
    template<typename A, typename B>
    static size_t compute(const std::pair<A, B>& p) {
        size_t seed = 0;
        hash_combine(seed, compute(p.first));
        hash_combine(seed, compute(p.second));
        return seed;
    }

    // 3️⃣ tuple 类型（递归）
    template<typename Tuple, size_t Index = 0>
    static void tuple_hash_combine(size_t& seed, const Tuple& t) {
        if constexpr (Index < std::tuple_size_v<Tuple>) {
            hash_combine(seed, compute(std::get<Index>(t)));
            tuple_hash_combine<Tuple, Index + 1>(seed, t);
        }
    }

    template<typename... Ts>
    static size_t compute(const std::tuple<Ts...>& t) {
        size_t seed = 0;
        tuple_hash_combine(seed, t);
        return seed;
    }

    // 4️⃣ 容器类型（vector, array, set, etc.）
    template<typename Container>
    static auto compute(const Container& c) -> decltype(begin(c), end(c), size_t()) {
        size_t seed = 0;
        for (auto& x : c)
            hash_combine(seed, compute(x));
        return seed;
    }
};
```

## 六、字符串相关算法
### 1. Rabin Karp算法
一种用于 **字符串查找**（pattern matching）的算法，核心思想是：将字符串转换为数字（哈希值）， 利用Rabin fingerprint 思想提高哈希效率，再通过滑动窗口 + 哈希匹配来快速判断是否有子串与目标串相等。
它适用于：
- 查找一个字符串是否出现在另一个字符串中
- 多模式匹配（多个子串匹配）
#### i. 步骤：
1. 预处理目标串 `pattern` 的哈希值 `Hp`
2. 初始化主串中前 `m` 个字符的哈希值 `Hs`
3. 利用滑动窗口依次匹配（考虑哈希冲突：哈希值相等也要进行字符匹配）

#### ii. 哈希公式
```
假设我们将字符串当作一个 **进制数** 来处理：
给定一个字符串 `s = "abcd"`，我们用一个基数 `B`（如 31、131）和一个大质数 `MOD` 来构建哈希值。
哈希公式：
      H(s) = (s[0] * B^(m-1) + s[1] * B^(m-2) + ... + s[m-1] * B^0) % MOD
例如：
      s = "abc"  → H = ('a' * B^2 + 'b' * B^1 + 'c' * B^0) % MOD
```
#### iii. 滚动哈希公式（Rabin fingerprint 思想）
滑动窗口下，利用前一个子串的哈希值减少遍历计算
```
假设当前窗口的子串为 `s[i ... i+m-1]`，我们已经知道它的哈希值为 `H_i`。  
要计算下一个窗口 `s[i+1 ... i+m]` 的哈希值。
滚动哈希公式:
      H_{i+1} = ((H_i - s[i] * B^{m-1}) * B + s[i + m]) % MOD
例如："abc"是"bcd"的前子串，其哈希值为H("abc")
      H("bcd") = ((H("abc") - 'a' * B^2) * B + 'd' * B^0) % MOD
```
#### iV. RK算法模板
```
bool rabinKarp(const std::string& text, const std::string& pattern) {
    const int B = 131;             // 基数
    const int MOD = 1e9 + 7;       // 大素数，防止哈希冲突
    int n = text.size(), m = pattern.size();

    if (m > n) return false;

    long long hash_p = 0, hash_s = 0, power = 1;

    // 计算 pattern 的哈希值
    for (int i = 0; i < m; ++i) {
        hash_p = (hash_p * B + pattern[i]) % MOD;
        hash_s = (hash_s * B + text[i]) % MOD;
        if (i < m - 1) power = (power * B) % MOD;  // B^(m-1)
    }

    // 滑动窗口比较
    for (int i = 0; i <= n - m; ++i) {
        if (hash_s == hash_p && text.substr(i, m) == pattern)
            return true;
        if (i + m < n) {
            hash_s = (hash_s - text[i] * power % MOD + MOD) % MOD; // 去掉首字符
            hash_s = (hash_s * B + text[i + m]) % MOD;              // 加入尾字符
        }
    }

    return false;
}

```

### 2. Manacher算法
在 O(n) 时间内求一个字符串的最长回文子串长度。
#### i. 步骤：
1. 对字符串进行 **预处理**，在每个字符之间插入特殊字符（如 `#`），统一处理奇偶长度回文。例如：
原串: aba
处理后: ^#a#b#a#$
> `^` 和 `$` 用作边界，防止越界。

2. 使用 **中心扩展 + 对称性** 来加速：
   - 定义 `p[i]` 为以 `i` 为中心的回文半径（包括 `i` 自身）。
   - 用当前回文右边界 `r` 和中心 `c` 进行对称映射：$i_{mirror} = 2*c - i$
   - 如果 i 在 r 内，则 `p[i] = min(r - i, p[i_mirror])`，再尝试向两边扩展。

3. 历整个数组，记录最长回文长度和中心即可。




# 6 滑动窗口（Sliding Window）
一种高效解决子区间问题的算法技巧，常用于数组、字符串等线性结构中。
核心思想：用两个指针表示一个「窗口区间」，在遍历中**动态扩展和收缩窗口**，达到某种条件就处理结果。
## 一、定长窗口
长度固定，一个指针即可表示一个「窗口区间」。
### 步骤：
1. 进入窗口
2. 初始化定长窗口
3. 更新答案
4. 离开并为下个循环提前更新状态
### 定长滑动窗口模板

```
int maxVowels(string s, int k) { // Leetcode.1456
        int ans = 0, vowel = 0;
        for (int i = 0; i < s.length(); i++) {
            // 1. 进入窗口
            if (s[i] == 'a' || s[i] == 'e' || s[i] == 'i' || s[i] == 'o' || s[i] == 'u') {
                vowel++;
            }
            if (i < k - 1) { // 窗口大小不足 k
                continue;
            }
            // 2. 更新答案
            ans = max(ans, vowel);
            // 3. 离开窗口，为下一个循环做准备
            char out = s[i - k + 1];
            if (out == 'a' || out == 'e' || out == 'i' || out == 'o' || out == 'u') {
                vowel--;
            }
        }
        return ans;
    }
```

## 二、 不定长滑动窗口
滑动窗口相当于在维护一个**队列**。右指针的移动可以视作**入队**，左指针的移动可以视作**出队**。
### 应用场景：
1. 求最长子数组：在定长的基础上，增加一个左指针
2. 求最短子数组：同上
3. 求子数组个数：一般要考虑剪枝，排除或累加范围结果数量
	1. 越短越合法（小于、至多）：一般考虑ans += right - left + 1
	2. 越长越合法（大于、至少）：一般考虑ans += right - left或left
	3. 恰好型（恰好K个）：可将问题转化为两个至少做减法f(K) - f(k +1)，可封装至多解法函数做结果差，也可以用三指针+滑动窗口模拟f(K) - f(k +1)。
### 不定长滑动窗口模板
```
Leetcode.930
// 恰好型模板：封装至多解法函数做结果差
int numSubarraysWithSum(vector<int>& nums, int goal) {
	auto f = [&](int k) -> int {
		int left = 0, sum = 0, re = 0;
		for (int i = 0; i < nums.size(); i++) {
			sum += nums[i];
			while (left <= i && sum >= k) sum -= nums[left++];
			re += left;
		}
		return re;
	};
	return f(goal) - f(goal + 1);
}

// 恰好型模板：三指针+滑动窗口模拟f(K) - f(k +1)
int numSubarraysWithSum(vector<int>& nums, int goal) {
        int ans = 0, l1 = 0, l2 = 0, sum1 = 0, sum2 = 0;
        for (int r = 0; r < nums.size(); r++) {
            sum1 += nums[r];
            sum2 += nums[r];

            while (l1 <= r && sum1 >= goal) {
                sum1 -= nums[l1++];
            }
            while (l2 <= r && sum2 >= goal + 1) {
                sum2 -= nums[l2++];
            }

            ans += (l1 - l2);
        }
        return ans;
    }
```

# 8 枚举（Enum）

## 一、矩阵对角线遍历
### 1. 左上到右下
![[Pasted image 20250928004027.png]]
对于每条对角线，行号 i 减列号 j 是一个定值。比如正中间对角线（主对角线）的 `i−j` 恒为 0。
设 `k=i−j+n`，那么右上角那条对角线的 `k=0−(n−1)+n=1`，左下角那条对角线的 `k=(m−1)−0+n=m+n−1`，枚举 `k=1,2,3,…,m+n−1`，就相当于在从右上到左下，一条一条地枚举对角线。
下一步计算出每条对角线的 `j` 的最小值和最大值，就可以开始遍历对角线了。
当  `i=0` 时 `j` 取到最小值 `n−k`，但这个数不能是负数，所以最小的 `j`
 是 `max(n−k,0)`同理，最大的 `j` 是 `min(m+n−1−k,n−1)`。
遍历步骤：
1. 枚举`k = 1,……,m+n-1`
2. 枚举 `j = max(n−k,0),……,min(m+n−1−k,n−1)`
#### 矩阵下对角遍历模板：
```
vector<vector<int>> enumMatrix(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        // 第一排在右上，最后一排在左下
        // 每排从左上到右下
        // 令 k=i-j+n，那么右上角 k=1，左下角 k=m+n-1
        for (int k = 1; k < m + n; k++) {
            // 核心：计算 j 的最小值和最大值
            int min_j = max(n - k, 0); // i=0 的时候，j=n-k，但不能是负数
            int max_j = min(m + n - 1 - k, n - 1); // i=m-1 的时候，j=m+n-1-k，但不能超过 n-1
            vector<int> a;
            for (int j = min_j; j <= max_j; j++) {
                a.push_back(grid[k + j - n][j]); // 根据 k 的定义得 i=k+j-n
            }
            if (min_j > 0) { // 右上角三角形
                // 操作
            } else { // 左下角三角形（包括中间对角线）
                // 操作
            }
            for (int j = min_j; j <= max_j; j++) { // 写回原数组
                grid[k + j - n][j] = a[j - min_j];
            }
        }
        return grid;
    }

```
### 2. 左下到右上 

与`左上到右下`类似，设 `k=i+j`，那么左上角那条对角线的 `k=0`，右下角那条对角线的 `k=(m−1)+(n-1)=m+n−2`，枚举 `k=0,1,2,…,m+n−2`，就相当于在从左上到右下，一条一条地枚举对角线。
下一步遍历  `j` ，当 `i=m−1` 时 `j` 取到最小值 `k−m+1`，但这个数不能是负数，所以最小的 `j` 是 `max(k−m+1,0)；`同理，以最大的 `j` 是 `min(k,n−1)`。
遍历步骤：
1. 枚举`k = 0,1,……,m+n-2`,
2. 枚举`j = max(k−m+1,0),……,min(k,n−1)`
#### 矩阵上对角遍历模板
```
vector<int> enumMatrix(vector<vector<int>>& mat) {
        int m = mat.size(), n = mat[0].size();
        vector<int> ans;
        ans.reserve(m * n); // 预分配空间
        for (int k = 0; k < m + n - 1; k++) {
            int min_j = max(k - m + 1, 0);
            int max_j = min(k, n - 1);
            
            if (k % 2 == 0) { // 偶数：从左到右遍历
                for (int j = min_j; j <= max_j; j++) {
                    ans.push_back(mat[k - j][j]);
                }
            } else { // 奇数：从右到左遍历
                for (int j = max_j; j >= min_j; j--) {
                    ans.push_back(mat[k - j][j]);
                }
            }
        }
        return ans;
    }

```

# 9 二分算法（Binary）
**二分法**是一种高效的搜索算法，适用于**有序数组或范围**。它通过每次将搜索范围 **折半** 来逐步缩小目标元素的位置，从而大大减少查找时间。时间复杂度是 **O(log n)**。
## 一、应用场景：
有序数组中查值（某值、>=、>、<、<=），全部转化为从左到右遍历，可直接使用**地板函数**（有需要也可转成天花板函数）：
```
1. >= X
2. > X 等价于 >= X+1
3. < X 等价于 (>=X) - 1
4. <= X 等价于 (>X) - 1
```
		
### i. 求最小的答题模板和三种二分模板（地板函数）：
左端点L，右端点R。左闭，结果为L；右闭，结果为R + 1；右开，结果为R。
\*注意：此处是左F右T（地板函数）写法，与左T右F（天花板函数）写法思路一致，细节不同。
\*补充：没有左开右闭，因为mid向下取整，L+1\=\=R时，会死循环。可使用向上取整实现。

```
	return right;

int lower_bound(vector<int>& nums, int target) {
	int L = 0, R = nums.size() - 1;
	while (L <= R) { // LR可以重合
		int mid = L + (R - L) / 2; // 防溢出
		if (nums[mid] < target) {
			L = mid + 1;
		} else {
			R = mid - 1;
		}
	}
	return L; // L == R + 1
}

// 2. 左闭右开[L, R)
int lower_bound(vector<int>& nums, int target) {
	int L = 0, R = nums.size();
	while (L < R) { // LR不可以重合，会越界
		int mid = L + (R - L) / 2; // 防溢出
		if (nums[mid] < target) {
			L = mid + 1;
		} else {
			R = mid;
		}
	}
	return L; // L = R
}

// 3. 左开右开(L, R)
int lower_bound(vector<int>& nums, int target) {
	int L = -1, R = nums.size();
	while (L + 1 < R) { // LR不可以重合，会越界
		int mid = L + (R - L) / 2; // 防溢出
		if (nums[mid] < target) {
			L = mid;
		} else {
			R = mid;
		}
	}
	return R; // L + 1 = R
}
```

# 10 栈与队列（Stack and Queue）
## 一、基础概念
栈：先进后出
队列：先进先出

	它们不是容器，是容器适配器。

栈是以底层容器完成其所有的工作，对外提供统一的接口，底层容器是可插拔的，用vector、deque、list都可以。
C++中，栈与队列的缺省底层容器为deque。

## 二、栈里的元素在内存中是连续分布的吗
答：不一定，栈不是容器，是容器适配器，其底层容器可能是vector，也可能是deque或list。如果是vector，则是连续的；其他两种则不是。

## 三、 单调栈（Monotonic Stack）
对于需要维护最值序列，且只从一端存取的场景，即可使用单调栈。

### 单调栈模板
```
pair<vector<int>, vector<int>> nearestGreater(vector<int>& nums) {
    int n = nums.size();
    // left[i] 是 nums[i] 左侧最近的严格大于 nums[i] 的数的下标，若不存在则为 -1
    vector<int> left(n);
    vector<int> st{-1}; // 哨兵
    for (int i = 0; i < n; i++) {
        int x = nums[i];
        while (st.size() > 1 && nums[st.back()] <= x) { // 如果求严格小于，改成 >=
            st.pop_back();
        }
        left[i] = st.back();
        st.push_back(i);
    }

    // right[i] 是 nums[i] 右侧最近的严格大于 nums[i] 的数的下标，若不存在则为 n
    vector<int> right(n);
    st = {n}; // 哨兵
    for (int i = n - 1; i >= 0; i--) {
        int x = nums[i];
        while (st.size() > 1 && nums[st.back()] <= x) {
            st.pop_back();
        }
        right[i] = st.back();
        st.push_back(i);
    }

    return {left, right};
}
```

## 四、单调队列
单调双端队列更准确。
单调队列 = 滑动窗口 + 单调栈。必须先掌握滑动窗口和单调栈这两个知识点，再学单调队列。
问：入队、出队、更新答案，这三步的顺序如何思考？
答：有两种情况。如果更新答案时，用到的数据包含当前元素，那么就需要先入队，再更新答案；如果用到的数据不包含当前元素，那么就需要先更新答案，再入队。至于出队，一般写在前面，每遍历到一个新的元素，就看看队首元素是否失效（不满足要求），失效则弹出队首。
### 单调队列模版
```
// 计算 nums 的每个长为 k 的窗口的最大值
// 时间复杂度 O(n)，其中 n 是 nums 的长度
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    int n = nums.size();
    vector<int> ans(n - k + 1); // 窗口个数
    deque<int> q; // 双端队列

    for (int i = 0; i < n; i++) {
        // 1. 右边入
        while (!q.empty() && nums[q.back()] <= nums[i]) {
            q.pop_back(); // 维护 q 的单调性
        }
        q.push_back(i); // 注意保存的是下标，这样下面可以判断队首是否离开窗口

        // 2. 左边出
        int left = i - k + 1; // 窗口左端点
        if (q.front() < left) { // 队首离开窗口
            q.pop_front();
        }

        // 3. 在窗口左端点处记录答案
        if (left >= 0) {
            // 由于队首到队尾单调递减，所以窗口最大值就在队首
            ans[left] = nums[q.front()];
        }
    }
    return ans;
}
```

```
// preorder
void preorderTraversal(TreeNode* root, vector<int> &ans) {
	if (!root) {
		return;
	}
	ans.push_back(root->val);
	preorderTraversal(root->left, ans);
	preorderTraversal(root->right, ans);
}

// inorder
void inorderTraversal(TreeNode* root, vector<int> &ans) {
	if (!root) {
		return;
	}
	inorderTraversal(root->left, ans);
	ans.push_back(root->val);
	inorderTraversal(root->right, ans);
}

// postorder
void postorderTraversal(TreeNode* root, vector<int> &ans) {
	if (!root) {
		return;
	}
	postorderTraversal(root->left, ans);
	postorderTraversal(root->right, ans);
	ans.push_back(root->val);
}

// levelorder
vector<vector<int>> levelOrder(TreeNode* root) {
	if (!root) {
		return {};
	}
	vector<vector<int>> ans;
	deque<TreeNode*> q;
	q.push_back(root);
	while (!q.empty()) {
		vector<int> t;
		int i = q.size();
		while (i--) {
			auto node = q.front();
			q.pop_front();
			t.push_back(node->val);
			if (node->left) {
				q.push_back(node->left);
			}
			if (node->right) {
				q.push_back(node->right);
			}
		}
		ans.emplace_back(t);
	}
	return ans;
}
```

### 一般树最近公共祖先（LCA）模板
```
class LcaBinaryLifting {
    vector<int> depth;
    vector<long long> dis; // 如果是无权树（边权为 1），dis 可以去掉，用 depth 代替
    vector<vector<int>> pa;

public:
    LcaBinaryLifting(vector<vector<int>>& edges) {
        int n = edges.size() + 1;
        int m = bit_width((unsigned) n); // n 的二进制长度
        vector<vector<pair<int, int>>> g(n);
        for (auto& e : edges) {
            int x = e[0], y = e[1], w = e[2];
            g[x].emplace_back(y, w);
            g[y].emplace_back(x, w);
        }

        depth.resize(n);
        dis.resize(n);
        pa.resize(n, vector<int>(m, -1));

        auto dfs = [&](this auto&& dfs, int x, int fa) -> void {
            pa[x][0] = fa;
            for (auto& [y, w] : g[x]) {
                if (y != fa) {
                    depth[y] = depth[x] + 1;
                    dis[y] = dis[x] + w;
                    dfs(y, x);
                }
            }
        };
        dfs(0, -1);

        for (int i = 0; i < m - 1; i++) {
            for (int x = 0; x < n; x++) {
                if (int p = pa[x][i]; p != -1) {
                    pa[x][i + 1] = pa[p][i];
                }
            }
        }
    }

    int get_kth_ancestor(int node, int k) {
        for (; k; k &= k - 1) {
            node = pa[node][countr_zero((unsigned) k)];
        }
        return node;
    }

    // 返回 x 和 y 的最近公共祖先（节点编号从 0 开始）
    int get_lca(int x, int y) {
        if (depth[x] > depth[y]) {
            swap(x, y);
        }
        y = get_kth_ancestor(y, depth[y] - depth[x]); // 使 y 和 x 在同一深度
        if (y == x) {
            return x;
        }
        for (int i = pa[x].size() - 1; i >= 0; i--) {
            int px = pa[x][i], py = pa[y][i];
            if (px != py) {
                x = px;
                y = py; // 同时往上跳 2^i 步
            }
        }
        return pa[x][0];
    }

    // 返回 x 到 y 的距离（最短路长度）
    long long get_dis(int x, int y) {
        return dis[x] + dis[y] - dis[get_lca(x, y)] * 2;
    }
};
```

# 13 回溯算法（Backtracing）
回溯法也可以叫做回溯搜索法，它是一种搜索的方式。回溯是递归的副产品，只要有递归就会有回溯。
回溯的本质是穷举，穷举所有可能，可用剪枝提高效率。

![[Pasted image 20250714175722.png]]
回溯法解决的问题都可以抽象为树形结构（高度有限的N叉树），在集合中递归查找子集，集合的大小就构成了树的宽度，递归的深度就构成了树的深度。
## 回溯模板：
```


void backtracking(参数) {
    if (终止条件) {
        存放结果;
        return;
    }

    for (选择：本层集合中元素（树中节点孩子的数量就是集合的大小）) {
        处理节点;
        backtracking(路径，选择列表); // 递归
        回溯，撤销处理结果
    }
}
```

## ==*递归与回溯的对比==

| 项目         | 递归           | 回溯                |
| ---------- | ------------ | ----------------- |
| 本质         | 函数调用自身       | 一种搜索策略（尝试 + 撤回）   |
| 是否一定需要     | 是            | 通常基于递归实现          |

# 14 前缀和思想（Presum）
## 一、概念
一种常用的思想，尤其在处理 **区间和、区间查询、统计问题** 时特别高效。
给定一个数组 `a[1..n]`。定义前缀和数组 `s[i] = a[1] + a[2] + ... + a[i]`。
通过前缀和，以O(n)空间在 **O(1)** 时间求任意区间 `[l, r]` 的和：
$$sum(l,r)=s[r]−s[l−1]sum(l, r) = s[r] - s[l-1]sum(l,r)=s[r]−s[l−1]$$
## 二、应用场景
1. 区间和查询
2. 区间差分/更新：与差分数组结合，可以 O(1) 更新区间，O(n) 还原数组。
3. 二维前缀和：图像处理、棋盘问题（快速求矩形区域和）。公式：$$sum(x1,y1,x2,y2)=S[x2][y2]−S[x1−1][y2]−S[x2][y1−1]+S[x1−1][y1−1]$$
4. 统计问题：“和”，“出现次数”、“余数个数”、“奇偶性”等。
## 三、前缀和模板
```
#include <vector>
using namespace std;
class NumArray {
public:
    NumArray(vector<int>& nums) {
        _nums.resize(nums.size() + 1);
        for (int i = 1; i < _nums.size(); i++) {
            _nums[i] = _nums[i - 1] + nums[i - 1];
        }
    }
    
    int sumRange(int left, int right) {
        return _nums[right + 1] - _nums[left];
    }
private:
    vector<int> _nums;
};
```
## 四、常见变种
1. **前缀最大值/最小值**：快速得到区间最值。
2. **前缀异或**：`xor[l, r] = pre[r] ^ pre[l-1]`。
3. **前缀积（对数处理）**：避免溢出。
### 前缀积
#### 1. 数学推导
设数组 $a_1​,a_2​,…,a_n​$，假设每个 $a_i>0$（稍后处理 $a_i\le 0$的情况）。
定义前缀对数：$$L[i] = \ln a_1 + \ln a_2 + \cdots + \ln a_i.$$
那么区间 $[l,r]$ 的积为
$$\prod_{k=l}^{r} a_k = \exp\!\Big(\sum_{k=l}^{r} \ln a_k\Big).$$
而$$\sum_{k=l}^{r} \ln a_k = L[r] - L[l-1],$$
所以得到关键公式：$$\prod_{k=l}^{r} a_k\;=\;\exp\big(L[r]-L[l-1]\big).$$
这个推导仅用到对数的基本性质：$\ln(xy)=\ln x+\ln y$ 与 $\exp(\ln x)=x$。
#### 2 实际问题与处理
1. **零（0）**  
   - $\ln 0$ 不定义。若区间内有任一零，积为 0。  
   - 常用做法：在预处理同时维护 `zero_count[i]` = 前缀中 0 的个数；区间内若 `zero_count[r] - zero_count[l-1] > 0`，直接返回 0。

2. **负数**  
   - 对数只对正数定义。处理策略：把符号分离——记录前缀符号（偶数个负数 → 正，奇数个负数 → 负），对绝对值取对数：$$
     \prod a_k = (\pm 1) \exp\Big(\sum \ln |a_k|\Big)
     $$
   - 所以要维护 `sign_prefix[i]`（-1 或 1）与 `L[i]`（对绝对值取 ln）。

3. **精度与上下溢**
   - 用 `long double`（而不是 `double`）能提高精度与范围，但仍无法保证任意巨大积的精确整数结果。  
   - `exp(L)` 可能非常大导致 `inf`，或非常小导致下溢为 0（当实际值远小于浮点最小正数）。  
   - 如果只需 **数量级/位数估算**，用对数更稳定（见下）。

4. **位数估算**（避免直接还原）  
   - 若想知道整数积的十进制位数（不还原整数本身），可用 base-10 对数：
     $$
     D = \left\lfloor \sum_{k=l}^r \log_{10} |a_k| \right\rfloor + 1
     $$
   - 即用 `log10` 的前缀和能直接给位数。

5. **需要精确整数结果时**
   - 用任意精度整数库（如 GMP、`boost::multiprecision::cpp_int`）直接乘或用分治乘法（FFT/大整数乘法）。  
   - 对数方法无法给出精确整数，仅给近似值或指数/位数信息。
#### 3. 前缀积（对数处理）模板
```
// 前缀积（对数处理）
#include <vector>
using namespace std;

class PrefixProduct {
private:
    int n;
    vector<long double> pre_log_abs; // 前缀 log(|a_i|)
    vector<int> zero_cnt;           // 前缀 0 个数
    vector<int> neg_cnt;            // 前缀 负数个数

public:
    // 构造函数：传入数组
    PrefixProductLog(const vector<long long>& a) {
        n = a.size();
        pre_log_abs.assign(n+1, 0.0L);
        zero_cnt.assign(n+1, 0);
        neg_cnt.assign(n+1, 0);

        for (int i = 1; i <= n; ++i) {
            long long v = a[i-1];
            zero_cnt[i] = zero_cnt[i-1] + (v == 0);
            neg_cnt[i] = neg_cnt[i-1] + (v < 0);
            if (v == 0) {
                pre_log_abs[i] = pre_log_abs[i-1]; // 不增加
            } else {
                pre_log_abs[i] = pre_log_abs[i-1] + logl( fabsl((long double)v) );
            }
        }
    }

    // 检查区间内是否含 0
    bool hasZero(int l, int r) const {
        return (zero_cnt[r] - zero_cnt[l-1]) > 0;
    }

    // 区间符号：1 或 -1 （区间里负数个数是否为奇数）
    int rangeSign(int l, int r) const {
        int negs = neg_cnt[r] - neg_cnt[l-1];
        return (negs % 2 == 0) ? 1 : -1;
    }

    // 返回区间对数和（ln of abs product）
    long double rangeLogAbs(int l, int r) const {
        return pre_log_abs[r] - pre_log_abs[l-1];
    }

    // 返回近似乘积（long double）。若区间含 0，返回 0.
    long double rangeProductApprox(int l, int r) const {
        if (hasZero(l,r)) return 0.0L;
        long double lg = rangeLogAbs(l,r);
        long double res = expl(lg); // 可能溢出为 +inf
        return (rangeSign(l,r) == 1) ? res : -res;
    }

    // 返回十进制位数估计（若含0返回1，因为结果为0）
    long long rangeDigits(int l, int r) const {
        if (hasZero(l,r)) return 1;
        long double sum_log10 = rangeLogAbs(l,r) / logl(10.0L); // ln -> log10
        long long digits = (long long)floor(sum_log10) + 1;
        return digits;
    }
};
```

# 15 差分算法（Difference）
差分（Difference Array）本质上是对数组做 **区间更新、单点查询** 的一种技巧。
## 一、一维差分
### 1. 定义  

$$d[1] = a[1], \quad d[i] = a[i] - a[i-1] \ (i \geq 2)$$

还原：  
$$a[i] = \sum_{k=1}^i d[k]$$
### 2. 区间加法
对区间 `[l, r]` 加 `val`：
$$d[l]+=val,d[r+1]−=vald[l] += val, \quad d[r+1] -= vald[l]+=val,d[r+1]−=val$$
最后前缀和还原。

## 二、二维差分
### 1. 定义  
$$d[x][y] = a[x][y] - a[x-1][y] - a[x][y-1] + a[x-1][y-1]$$
还原：二维前缀和：  
$$a[x][y] = \sum_{i=1}^x \sum_{j=1}^y d[i][j]$$
### 2. 子矩阵加法  
对子矩阵 `[x1..x2][y1..y2]` 加 `val`：
```text
d[x1][y1]     += val
d[x1][y2+1]   -= val
d[x2+1][y1]   -= val
d[x2+1][y2+1] += val
```
最后二维前缀和还原
## 三、差分约束系统
### 形式

$$xj−xi≤cx_j - x_i \leq cxj​−xi​≤c$$
转化为图：
- 点：变量
- 边：`i -> j`，权值 = c
- 求解：最短路（Bellman-Ford / SPFA）
## 四、典型应用
- 一维：区间加值、区间覆盖次数
- 二维：子矩阵加值（图像处理、地图操作）
- 差分约束：调度、不等式系统
- 扩展：结合扫描线 → 处理区间/矩形覆盖

## 懒删除堆
支持延迟删除元素的堆。
### 核心思想：
不立刻从堆中删除元素，而是**标记为“已删除”**，等它被弹出时再真正忽略。
### 实现方式：
1. 堆维护已删除元素
2. 哈希表维护已删除元素
### 模板
```
#include <queue>
#include <unordered_map>
using namespace std;

// 模板来源 https://leetcode.cn/circle/discuss/mOr1u6/
// 最大堆 LazyHeap<int> max_pq;
// 最小堆 LazyHeap<int, greater<int>> min_pq;
template<typename T, typename Compare = less<T>>
class LazyHeap {
    priority_queue<T, vector<T>, Compare> pq;
    unordered_map<T, int> remove_cnt; // 每个元素剩余需要删除的次数
    size_t sz = 0; // 堆的实际大小

    // 正式执行删除操作
    void apply_remove() {
        while (!pq.empty() && remove_cnt[pq.top()] > 0) {
            remove_cnt[pq.top()]--;
            pq.pop();
        }
    }

public:
    // 删除堆中所有应该删除的元素后，堆的实际大小
    size_t size() {
        return sz;
    }

    // 删除
    void remove(T x) {
        remove_cnt[x]++; // 懒删除
        sz--;
    }

    // 查看堆顶
    T top() {
        apply_remove();
        return pq.top(); // 真正的堆顶
    }

    // 出堆
    T pop() {
        apply_remove();
        sz--;
        T x = pq.top();
        pq.pop();
        return x;
    }

    // 入堆
    void push(T x) {
        if (remove_cnt[x] > 0) {
            remove_cnt[x]--; // 抵消之前的删除
        } else {
            pq.push(x);
        }
        sz++;
    }
};

```

通过构建路径实现快速检索和前缀匹配，节点压缩技术与动态内存管理可优化存储效率。
## 字典树模板：
```
struct Node {
    Node* son[26];
    bool end = false;
};
class Trie {
public:
    Trie() {
        
    }

    ~Trie() {
        destory(root);
    }
    
    void insert(string word) {
        Node *cur = root;
        for (char c : word) {
            c -= 'a';
            if (cur->son[c] == nullptr) {
                cur->son[c] = new Node();
            }
            cur = cur->son[c];
        }
        cur->end = true;
    }
    
    bool search(string word) {
        return find(word) == 2;
    }
    
    bool startsWith(string prefix) {
        return find(prefix) != 0;
    }
private:
    Node *root = new Node();
    int find(string word) {
        Node *cur = root;
        for (char c : word) {
            c -= 'a';
            if (cur->son[c] == nullptr) {
                return 0;
            }
            cur = cur->son[c];
        }
        return cur->end ? 2 : 1; // 2为完全匹配，1为前缀匹配
    }

    void destory(Node *node) {
        if (node == nullptr) {
            return;
        }
        for (Node *son : node->son) {
            destory(son);
        }
        delete node;
    }  
};
```

# 18 并查集（Union Find）
## 🧩 一、定义
**并查集（Union-Find）**是一种用于**动态维护若干不相交集合**的数据结构。  
它支持两种核心操作：
1. **Find(x)**：查找元素 `x` 所在集合的代表（根节点）。
2. **Union(x, y)**：将包含 `x` 和 `y` 的两个集合合并。
常用于解决：
- 连通性问题（如图的连通分量）
- 动态分组问题（如朋友圈、网络连接）
- Kruskal 最小生成树算法
- 判断图中是否存在环
## ⚙️ 二、核心思想
每个集合用一棵「树」表示，**每个节点的父指针 `parent[x]` 指向它的父节点**。
- 树的根节点代表整个集合。
- `parent[root] == root`。

## 🧠 三、基本操作
### 1️⃣ Find（查找根节点）
递归实现：
```
int find(int x) {
    if (parent[x] != x) parent[x] = find(parent[x]); // 路径压缩
    return parent[x];
}
```
路径压缩的作用：
> 把节点直接挂到根上，使后续查找几乎为 O(1)。
---
### 2️⃣ Union（合并集合）
```
void unite(int x, int y) {
    int rx = find(x);
    int ry = find(y);
    if (rx == ry) return;
    // 可选：按秩（rank）合并，保持树更平衡
    if (rank[rx] < rank[ry]) swap(rx, ry);
    parent[ry] = rx;
    if (rank[rx] == rank[ry]) rank[rx]++;
}

```

## ⏱️ 四、复杂度分析

| 操作    | 时间复杂度（均摊） |
| ----- | --------- |
| Find  | O(α(n))   |
| Union | O(α(n))   |
其中α(n) 是 **反 Ackermann 函数**，增长极慢，在实际中可认为是常数时间。

## ✅ 五、完整模板代码
```
// 模板来源 https://leetcode.cn/circle/discuss/mOr1u6/
class UnionFind {
    vector<int> fa; // 代表元
    vector<int> sz; // 集合大小

public:
    int cc; // 连通块个数

    UnionFind(int n) : fa(n), sz(n, 1), cc(n) {
        // 一开始有 n 个集合 {0}, {1}, ..., {n-1}
        // 集合 i 的代表元是自己，大小为 1
        ranges::iota(fa, 0); // iota(fa.begin(), fa.end(), 0);
    }

    // 返回 x 所在集合的代表元
    // 同时做路径压缩，也就是把 x 所在集合中的所有元素的 fa 都改成代表元
    int find(int x) {
        // 如果 fa[x] == x，则表示 x 是代表元
        if (fa[x] != x) {
            fa[x] = find(fa[x]); // fa 改成代表元
        }
        return fa[x];
    }

    // 判断 x 和 y 是否在同一个集合
    bool is_same(int x, int y) {
        // 如果 x 的代表元和 y 的代表元相同，那么 x 和 y 就在同一个集合
        // 这就是代表元的作用：用来快速判断两个元素是否在同一个集合
        return find(x) == find(y);
    }

    // 把 from 所在集合合并到 to 所在集合中
    // 返回是否合并成功
    bool merge(int from, int to) {
        int x = find(from), y = find(to);
        if (x == y) { // from 和 to 在同一个集合，不做合并
            return false;
        }
        fa[x] = y; // 合并集合。修改后就可以认为 from 和 to 在同一个集合了
        sz[y] += sz[x]; // 更新集合大小（注意集合大小保存在代表元上）
        // 无需更新 sz[x]，因为我们不用 sz[x] 而是用 sz[find(x)] 获取集合大小，但 find(x) == y，我们不会再访问 sz[x]
        cc--; // 成功合并，连通块个数减一
        return true;
    }

    // 返回 x 所在集合的大小
    int get_size(int x) {
        return sz[find(x)]; // 集合大小保存在代表元上
    }
};
```


# 19 数组树与线段树（Binary Indexed Tree and Segment Tree）
## Fenwick 树（树状数组 / Binary Indexed Tree, BIT）
### 📌 简介
- **Fenwick Tree** 又称 **Binary Indexed Tree (BIT)**  
- 提出者：Peter M. Fenwick（1994）  
- 中文常译为 **树状数组**  
- 用途：动态维护数组的 **前缀和**，支持 **单点更新** 和 **前缀查询**，复杂度均为 **O(log n)**。
### 🧩 原理
Lowbit 运算：用最低位的`1`表示区间范围 $$lowbit(x) = x \& -x$$
区间范围：$[i - lowbit(i) + 1, i]$
例如：n=8
```
tree[1] = a1
tree[2] = a1+a2
tree[3] = a3
tree[4] = a1+a2+a3+a4
tree[5] = a5
tree[6] = a5+a6
tree[7] = a7
tree[8] = a1+...+a8
```
 
 ### 树状数组模板：
```
// 树状数组(Fenwick Tree, Binary indexed Tree)
template<typename T>
class FenwickTree {
public:
    FenwickTree(int n) : _tree(n + 1) {}; // 使用下标1 ~ n+1

    void update(int i, T val) { // a[i] 增加 val
        for (; i < _tree.size(); i += i & -i) {
            _tree[i] += val;
        }
    }

    T pre(int i) const {// 求前缀和 a[1] + ... + a[i]
        T res = 0;
        // i &= i - 1 等价于 i -= i & -i
        // 含义均为 清除最低位的1
        for (; i > 0; i &= i - 1) {
            res += _tree[i];
        }
        return res;
    }

    T range(int l, int r) const { 
        return pre(r) - pre(l - 1); 
    }

private:
    vector<T> _tree;
};
```

# 20 贪心算法（Greedy）
一种在每一步选择中都采取在当前状态下最优（即最有利）的选择，希望通过一系列局部最优选择，最终达到全局最优或近似最优。

## 一、特点
- **局部最优选择**：每一步都做出当前最优解。
- **不回溯**：一旦作出选择，就不会回头更改。
- **高效率**：通常时间复杂度低（如 `O(nlogn)`，`O(n)`），适用于对速度要求高的问题。

## 二、适用条件
贪心算法并不适用于所有问题。只有在满足以下两个条件时，它才能得到正确结果：
1. **贪心选择性质（Greedy Choice Property）**  当前局部最优选择能扩展为全局最优解的一部分。
2. **最优子结构性质（Optimal Substructure）**  问题的最优解包含子问题的最优解。
如果不满足这两个条件，可能无法得到正确答案。

**贪心没有套路，说白了就是常识性推导加上举反例**。

# 21 动态规划（Dynamic Programming）
一种 **将复杂问题分解为更小子问题** 的方法，通过保存子问题的中间结果（**记忆化/表格法**）避免重复计算，从而提高效率。
## 一、适用条件
- **最优子结构**：  一个问题的最优解包含子问题的最优解。
- **子问题重叠**：  同一个子问题会被重复计算多次。
## 二、核心思想
**"记忆 + 递推/递归"**：保存子问题解，逐步构建出大问题的解。
## 三、常用形式：
- **自顶向下（递归 + 记忆化）**
- **自底向上（循环 + DP数组）**
## 四、步骤：
1. 确定dp数组（dp table）以及下标的含义
2. 确定递推公式
3. dp数组如何初始化
4. 确定遍历顺序
5. 举例推导dp数组

## ==*DP VS Greedy==

| 特点/区别      | 动态规划（DP）            | 贪心算法（Greedy）         |
| ---------- | ------------------- | -------------------- |
| **是否回溯选择** | ✅ 会保留所有子问题结果，比较找最优  | ❌ 只做出当下最优选择，不回头      |
| **解法策略**   | 尝试所有可能，保存中间结果       | 每步都选局部最优             |
| **适用场景**   | 存在**重叠子问题 + 最优子结构** | 具有**贪心选择性质 + 最优子结构** |
| **是否保证最优** | ✅ 保证最优解             | ❌ 不一定最优（只在某些问题中是）    |
| **效率对比**   | 较高（但比贪心慢）           | 高效，通常时间复杂度更低         |
| **实现方式**   | 通常需要表格/数组           | 一般只需排序 + 简单循环        |
|            |                     |                      |

### 1. 拓扑排序
#### 1️⃣ 概念
- 拓扑排序用于 **有向无环图（DAG, Directed Acyclic Graph）**。
- 目的是对图的节点进行线性排序，使得每条边 `(u -> v)` 中 `u` 在 `v` 之前。
- **应用场景**：
  - 任务调度（任务依赖顺序）
  - 编译顺序
  - 课程安排
#### 2️⃣ 常用方法
##### 方法 A：DFS 版

**思路**：
1. 对图进行 DFS。
2. 在 DFS 递归结束时，把当前节点加入结果列表。
3. 最后将列表 **反转** 得到拓扑序。
**特点**：
- 时间复杂度 O(V + E)
- 适合找任意一个拓扑序
- 可以配合 **检测环**（有环则 DFS 时遇到灰色节点）
###### 图的拓扑排序模板（DFS版）
```
void dfs(int u, vector<vector<int>>& g, vector<bool>& vis, vector<int>& topo) {
    vis[u] = true;
    for (int v : g[u]) {
        if (!vis[v]) dfs(v, g, vis, topo);
    }
    topo.push_back(u); // 后序加入
}

vector<int> topologicalSortDFS(int n, vector<vector<int>>& g) {
    vector<bool> vis(n, false);
    vector<int> topo;
    for (int i = 0; i < n; i++)
        if (!vis[i])
            dfs(i, g, vis, topo);
    reverse(topo.begin(), topo.end());
    return topo;
}

```

##### 方法 B：Kahn 算法（BFS 版）
**思路**：
1. 统计每个节点的入度 `indegree[i]`。
2. 将入度为 0 的节点加入队列。
3. 队列非空时：
    - 弹出节点 `u`，加入拓扑序
    - 遍历 `u` 的出边 `(u -> v)`：
        - `indegree[v]--`
        - 若 `indegree[v] == 0`，入队
4. 遍历完成，如果拓扑序长度 < 节点数，则说明有环。
**特点**：
- 时间复杂度 O(V + E)
- 可检测环
- 适合依赖调度问题
###### 图的拓扑排序模板（Kahn版）
```
vector<int> topologicalSortKahn(int n, vector<vector<int>>& g) {
    vector<int> indegree(n, 0);
    for (int u = 0; u < n; u++)
        for (int v : g[u])
            indegree[v]++;
    
    queue<int> q;
    for (int i = 0; i < n; i++)
        if (indegree[i] == 0) q.push(i);

    vector<int> topo;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        topo.push_back(u);
        for (int v : g[u]) {
            if (--indegree[v] == 0) q.push(v);
        }
    }

    if (topo.size() < n) return {}; // 图有环
    return topo;
}

```

## 蓄水池抽样算法 (Reservoir Sampling)

### 一、问题背景
- 数据流元素个数 **N 未知** 或 **过大无法一次性存储**。
- 目标：**从数据流中随机抽取一个或若干元素**，保证等概率。

传统方法：存下所有元素再随机抽取 → 不可行。  
解决方案：**蓄水池抽样**。

---

### 二、基本思想

#### 抽取 1 个元素 (k = 1)
1. 初始化：蓄水池存第 1 个元素；
2. 第 i 个元素到来时 (i ≥ 2)：  
   - 以 **1/i 概率** 替换蓄水池元素；
   - 否则保持不变。

#### 抽取 k 个元素 (k > 1)
1. 前 k 个元素直接放入蓄水池；
2. 从第 (k+1) 个元素开始：  
   - 以 **k/i 概率** 选中该元素；
   - 如果选中，则随机替换蓄水池中的一个元素。

---

### 三、概率证明

- 第 j 个元素最终被选中概率：
  - **k = 1**：  
    $$
    P = \frac{1}{j} \times \frac{j}{j+1} \times \frac{j+1}{j+2} \times \dots \times \frac{N-1}{N} = \frac{1}{N}
    $$
  - **k > 1**：  
    每个元素最终概率均为 ($\frac{k}{N}$)。

---

### 四、蓄水池抽样算法模板

-  k = 1
```cpp
int reservoirSampling(const vector<int>& stream) {
    srand(time(0));
    int chosen = stream[0];
    for (int i = 1; i < stream.size(); i++) {
        int j = rand() % (i + 1); // 随机 [0..i]
        if (j == 0) {             // 以 1/(i+1) 概率替换
            chosen = stream[i];
        }
    }
    return chosen;
}
```
- k > 1
```cpp
vector<int> reservoirSampling(const vector<int>& stream, int k) {
    srand(time(0));
    vector<int> reservoir(stream.begin(), stream.begin() + k);
    for (int i = k; i < stream.size(); i++) {
        int j = rand() % (i + 1); // 随机 [0..i]
        if (j < k) {
            reservoir[j] = stream[i];
        }
    }
    return reservoir;
}

```

### 五、应用场景
- 数据流随机抽样（日志流、传感器数据）。
- 大文件随机行抽取。
- 在线算法 (online algorithm)，适用于未知大小的数据。

##
