## 一、推理优化的核心概念
1. **推理（Inference）**
    - 模型在训练完成后处理实际输入生成预测的阶段。
    - 与训练阶段不同：训练注重精度，推理注重**性能（速度、延迟、吞吐量）**。
2. **核心指标**
    - **延迟（Latency）**：单条输入处理时间。
    - **吞吐量（Throughput）**：单位时间处理的输入数量。
    - **内存占用（Memory footprint）**：模型及中间缓存占用。
    - **能效（Energy efficiency）**：每次推理功耗。
    - **精度保持（Accuracy retention）**：优化后模型尽量不损失精度。
3. **优化策略分类**
    - **算子/算术级**：减少计算量、替换高效算子、量化等。
    - **模型结构级**：剪枝、蒸馏、重参数化。
    - **硬件级**：针对 CPU/GPU/TPU/NPU 做特定优化。
    - **系统/编译器级**：算子融合、图优化、缓存优化。

## 二、算子与算术级优化
1. **低精度计算（Quantization）**
    - 将浮点运算（FP32）转换为低精度（INT8、FP16、BF16）。
    - **类型：**
		- **动态量化（Dynamic Quantization）**：推理时才进行缩放。
		- **静态量化（Static Quantization）**：推理前就确定缩放因子。
		- **混合精度（Mixed Precision）**：部分敏感层保持高精度。
    - **收益**：内存占用 ↓50–75%，速度 ↑1.5–4×，功耗下降；精度轻微下降（取决于量化方案）。
2. **算子融合（Operator Fusion）**
    - 将多个连续算子合并为一个执行，减少内存访问和调度开销。
    - 示例：Conv + BatchNorm + ReLU → fused_conv
    - **收益**：延迟下降 10–40%，吞吐量提高。
3. **内存优化**
    - 缓冲区复用、张量布局优化（NHWC ↔ NCHW）。
    - **收益**：峰值内存 ↓30–60%，减少缓存开销，延迟略下降。
4. **稀疏计算（Sparse computation）**
    - 利用权重或激活稀疏性跳过无效计算。
    - **收益**：计算量 ↓30–90%，加速潜力高，但依赖硬件支持。

## 三、模型结构级优化
1. **模型剪枝（Pruning）**
    - 去掉不重要权重或通道。
    - **方法：**
		- **非结构化剪枝（Unstructured pruning）**：剪掉单个权重。
		- **结构化剪枝（Structured pruning）**：剪掉整个卷积通道或层。
    - **收益**：FLOPs ↓20–80%，模型大小 ↓20–70%，速度 ↑10–50%，精度略下降。
2. **模型蒸馏（Knowledge Distillation）**
    - 训练小模型模仿大模型行为。
    - **收益**：模型 ↓50–80%，速度 ↑2–5×，精度可保持或轻微下降。
3. **重参数化（Reparameterization）**
    - 将训练阶段复杂结构合并为推理阶段单层。
    - **收益**：速度 ↑10–50%，内存略下降，训练复杂度增加。
4. **轻量化设计 / NAS**
    - 自动搜索推理友好结构。
    - **收益**：延迟 ↓30–70%，吞吐量 ↑，功耗 ↓，精度可保持。

## 四、硬件级优化
1. **CPU优化**
    - **方法：**
	    - 利用 SIMD 指令集（AVX, AVX512）。
		- 多线程/并行计算。
		- 张量布局优化（NCHW/NHWC 对齐缓存）。
    - **收益**：速度 ↑2–10×，延迟下降，能效提升。
2. **GPU优化**
	- **方法：**
		- Tensor Core 利用 FP16 / INT8 运算。
		- Kernel fusion（减少 GPU kernel launch 开销）。
		- 内存带宽优化：尽量减少显存访问。
    - **收益**：速度 ↑3–10×，功耗下降，显存访问优化。
3. **专用推理芯片（TPU/NPU/Edge AI）**
    - **方法：**
	    - 设计低精度、高吞吐量算子。
		- 图优化和流水线计算。
    - **收益**：极低延迟，吞吐量 ↑5–20×，功耗显著下降。

## 五、系统与编译器优化
1. **图优化（Graph Optimization）**
    - 常量折叠、算子融合、死代码消除。
    - **收益**：延迟 ↓10–50%，内存 ↓10–40%，吞吐量 ↑。
2. **内存调度与流水线**
    - 合理安排计算顺序与缓存
    - 减少峰值内存占用和中间复制。
    - **收益**：峰值内存 ↓20–50%，延迟稳定，吞吐量 ↑。
3. **批处理优化（Batching / Dynamic Batching）**
    - 将小输入合并处理以提高吞吐量。
    - **收益**：吞吐量 ↑2–10×，单条延迟可能略升。

## 六、实践经验与注意事项
- 剪枝通常先做再量化效果更好。
- 后训练量化快，但精度略降；量化感知训练精度最好。
- 单输入低延迟与大批量高吞吐量通常冲突。
- 硬件支持的低精度类型不同，需要匹配。

## 七、未来趋势
- **自动化优化**：NAS + 编译器生成最优推理模型。
- **混合精度与混合架构**：不同层使用不同精度或硬件加速。
- **稀疏/低秩网络**：结合稀疏计算硬件实现高能效。
- **跨平台统一优化**：模型可高效推理于 CPU、GPU、NPU、Edge AI。
