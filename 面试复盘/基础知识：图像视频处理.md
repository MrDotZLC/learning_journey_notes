## Diffusion模型
### 概念
Diffusion（扩散模型） 是一类生成模型，核心思想来自热力学中的扩散现象：先逐步给数据加噪声直到变成纯随机噪声，再训练模型学会把这个过程逆转，从噪声一步步还原出数据。

它和 GAN、VAE 并列为三大主流生成模型，但相比 GAN 训练更稳定、生成质量更高，是目前图像生成（Stable Diffusion、DALL·E、Midjourney）、视频生成、音频生成的主流方案。

Diffusion 推理就是"从一团随机噪声开始，让神经网络反复预测并减去噪声，逐步雕刻出一张图"的过程。

```
文本提示 → CLIP 文本编码器 → 文本 embedding
                              ↓
纯噪声 latent (64×64×4) → U-Net 反复去噪（cross-attention 注入文本条件）
                              ↓
                        VAE 解码器
                              ↓
                        512×512 图像
```
### U-Net 
在 Diffusion 中，它被用作**噪声预测网络** ε_θ(x_t, t)，是整个扩散模型的核心骨干。
#### 整体结构：编码器-解码器 + 跳跃连接
```
输入 x_t (H×W×C)
    │
┌───▼───┐  Down Block 1
│ Conv  │─────────────── skip ──────────────┐
│ Conv  │                                   │
└───┬───┘                                   │
    │ Downsample                            │
┌───▼───┐  Down Block 2                     │
│ Conv  │─────────────── skip ──────────┐   │
│ Conv  │                               │   │
└───┬───┘                               │   │
    │ Downsample                        │   │
┌───▼───┐  Down Block 3                 │   │
│ Conv  │─────────── skip ─────────┐    │   │
│ Conv  │                          │    │   │
└───┬───┘                          │    │   │
    │ Downsample                   │    │   │
┌───▼───────┐  Bottleneck          │    │   │
│ Conv+Attn │  (最低分辨率)         │    │   │
│ Conv+Attn │                      │    │   │
└───┬───────┘                      │    │   │
    │ Upsample                     │    │   │
┌───▼───┐  Up Block 3              │    │   │
│ Concat│◄─────────────────────────┘    │   │
│ Conv  │                               │   │
│ Conv  │                               │   │
└───┬───┘                               │   │
    │ Upsample                          │   │
┌───▼───┐  Up Block 2                   │   │
│ Concat│◄──────────────────────────────┘   │
│ Conv  │                                   │
│ Conv  │                                   │
└───┬───┘                                   │
    │ Upsample                              │
┌───▼───┐  Up Block 1                       │
│ Concat│◄──────────────────────────────────┘
│ Conv  │
│ Conv  │
└───┬───┘
    │
输出 ε_θ (H×W×C)  预测的噪声
```
**核心特点：**
- **下采样路径（Encoder）**：逐步降低空间分辨率，提取高层语义
- **上采样路径（Decoder）**：逐步恢复空间分辨率
- **跳跃连接（Skip Connection）**：把编码器同层特征直接拼接到解码器，保留细节信息
#### Diffusion U-Net 的关键组件
1. 残差块（ResNet Block）
	每个 Conv 层通常包在残差块里：
	```
	x → GroupNorm → SiLU → Conv → (+ time embedding) → GroupNorm → SiLU → Conv → + x
	```
	- 用 **GroupNorm** 而非 BatchNorm（对 batch size 不敏感）
	- 激活函数用 **SiLU / Swish**

2. 时间步嵌入（Time Embedding）
	因为同一个网络要处理所有 t，必须告诉它"现在是第几步"：
	```
	t → 正弦位置编码 → MLP → 每个 ResBlock 中注入（加法或 FiLM）
	```
	这相当于给网络一个"噪声程度"的条件信号。

3. 自注意力（Self-Attention）
	- 通常在**低分辨率层**（如 16×16、8×8）加入
	- 让远距离像素相互影响，捕捉全局结构
	- 高分辨率层用注意力太贵，所以只在瓶颈处用

4. 交叉注意力（Cross-Attention）—— Stable Diffusion 的关键
	在文本条件生成中，U-Net 每层插入：
	```
	Q = 图像特征
	K, V = 文本 embedding（来自 CLIP）
	Attention(Q, K, V)
	```
	这就是"文本控制图像"的机制——图像特征去"查询"文本信息。

### DiT (Diffusion Transformer)
旨在利用 Transformer 的可扩展性来提升生成性能，本质是个降噪器，沿用了 ViT 结构。
先通过 VAE 将图像压缩到 latent space，然后 DiT Transformer 预测噪声，最后通过 VAE Decoder 恢复图像。整体流程是“编码 — 去噪 — 解码”的混合范式

```
Text Prompt / Class Label
          |
          v
Condition Encoder
          |
          v
Random Noise Latent zT
          |
          v
+-----------------------+
| Diffusion Sampling    |
|                       |
|  timestep loop        |
|                       |
|  zt                   |
|   |                   |
|   v                   |
| Patchify              |
|   |                   |
|   v                   |
| DiT Transformer       |
|   |                   |
|   v                   |
| Noise Prediction eps  |
|   |                   |
|   v                   |
| Scheduler Step        |
|                       |
+-----------------------+
          |
          v
Clean Latent z0
          |
          v
VAE Decoder
          |
          v
Image
```

#### 步骤 ①：初始化随机 Latent Noise 

VAE 编码 —— 从像素空间进入潜在空间。

**做什么**：用预训练的自编码器（通常是 VAE 或 VQ-VAE）的编码器 `E`，把 256×256×3 的 RGB 图像压缩成 32×32×4 的潜在特征图。

**为什么这样做**：

- 像素空间维度极高（256×256×3 ≈ 196k 维），直接在像素上做扩散计算量巨大。
- 潜在空间把空间尺寸缩小 8 倍、通道从 3 变 4，总压缩率约 **48 倍**。
- 扩散模型只需建模潜在空间的分布，语义信息保留，像素级细节交给解码器恢复。

**关键点**：这个 VAE 在 DiT 训练全程**冻结**，不参与梯度更新。DiT 只学习潜在空间中的去噪。这也意味着最终生成质量受 VAE 重建能力上限约束。

**论文细节**：DiT 使用的是 Stable Diffusion 同款 VAE，下采样因子 f=8，潜在通道数 4。

---

### 步骤 ②：DiT 主干网络 —— 核心去噪器

这是 DiT 最关键的部分，输入 `z_t`、`t`、`y`，输出预测噪声。下面拆成子步骤。

#### 3.1 Patchify —— 把图像变成 Token 序列

**做什么**：把 `z_t`（32×32×4）切成不重叠的 Patch。以 Patch 尺寸 `p=2` 为例，得到 `(32/2)×(32/2) = 16×16 = 256` 个 Patch，每个 Patch 展平后是 `2×2×4 = 16` 维向量，再经线性层投影到隐藏维度 `d`（如 1152）。

**类比**：这完全借用了 ViT 的做法，把图像当作“视觉句子”，每个 Patch 是一个“词”。

**Patch 尺寸的影响**：

- `p=2` → 256 个 Token；`p=4` → 64 个 Token；`p=8` → 16 个 Token。
- Patch 越小，Token 越多，自注意力计算量按 **平方** 增长，但生成质量通常更好。
- 论文中 DiT-XL/2 的 `/2` 就表示 Patch 尺寸为 2。

#### 3.2 位置编码 —— 注入空间信息

**做什么**：自注意力本身对顺序不敏感，必须显式加入位置信息。DiT 使用 **二维正弦-余弦位置编码**，为每个 Patch 的 (行, 列) 位置生成编码向量，加到 Token 上。

**为什么不用可学习位置编码**：论文发现 sincos 二维编码在分辨率泛化上更稳，且无需额外参数。后续研究（如 SD3、Sora）多改用 RoPE 及其二维变体。

#### 3.3 条件嵌入 —— 注入时间步与类别

**做什么**：把时间步 `t` 和类别 `y` 变成向量，供后续 AdaLN 使用。

**具体流程**：

1. `t` 经正弦位置编码 → MLP → 得到 `t_emb`。
2. `y` 经可学习嵌入表 → 得到 `y_emb`。
3. 两者**相加**得到条件向量 `c = t_emb + y_emb`。

**注意**：DiT 论文中也尝试过把 `c` 作为额外 Token 拼接到序列（in-context conditioning）、或通过交叉注意力注入，但最终 **adaLN-Zero** 效果最好、计算最省。

#### 3.4 DiT Block —— 堆叠的 Transformer 层

每个 DiT Block 包含两个子层，均采用 **adaLN-Zero** 调制：

**子层一：自注意力**

```
h = x + gate_msa · MHSA( (1 + scale_msa) · LayerNorm(x) + shift_msa )
```

- `LayerNorm(x)`：标准层归一化。
- `scale_msa, shift_msa`：由条件向量 `c` 经 MLP 生成，对归一化结果做逐通道缩放和平移。
- `MHSA`：多头自注意力，每个 Token 与所有 Token 交互，捕捉全局依赖。
- `gate_msa`：门控标量，**零初始化**，使 Block 初始时近似恒等映射。

**子层二：MLP**

```
h = h + gate_mlp · MLP( (1 + scale_mlp) · LayerNorm(h) + shift_mlp )
```

结构与子层一类似，MLP 通常是两层线性 + GELU，隐藏维度是 `d` 的 4 倍。

**为什么 adaLN-Zero 有效**：

- 条件信息通过调制归一化统计量注入，比交叉注意力更轻量。
- 门控零初始化让每个 Block 训练初期“静默”，梯度稳定，深层网络易训练。
- 论文消融显示，adaLN-Zero 比 in-context、cross-attention、adaLN 都更好，且 Gflops 最低。

**堆叠数量**：DiT-S/B/L/XL 分别堆叠 12/12/24/28 个 Block，隐藏维度 384/768/1024/1152，注意力头数 6/12/16/16。

#### 3.5 Final Layer 与 Unpatchify —— 回到潜在空间形状

**做什么**：

1. 对最后一个 Block 的输出做 LayerNorm，再用 `c` 生成 `scale, shift` 做 AdaLN 调制。
2. 线性投影到 `p×p×C` 维度（如 2×2×4 = 16）。
3. **Unpatchify**：把 Token 序列重排回 `32×32×4` 的潜在特征图。
4. 输出预测的噪声 `ε_θ`（或 `x₀` / `v`）。

**关键点**：Final Layer 的 AdaLN 调制**不带门控**，且线性层权重初始化为零，进一步稳定训练起点。

### 步骤 ④：计算损失

**做什么**：用预测噪声与真实噪声的均方误差作为损失。

```
L_simple = E_{z₀, ε, t, y} [ || ε - ε_θ(z_t, t, y) ||² ]
```

**变体**：也可以让网络预测 `x₀` 或速度 `v = √(ᾱ_t)·ε - √(1-ᾱ_t)·z₀`。论文发现预测 `ε` 和 `v` 差别不大，但 `x₀` 略差。实际中 SD3 等采用 v-prediction 或 flow matching。

**反向传播**：梯度只更新 DiT 参数，VAE 冻结。

---

### 步骤 ⑤：推理去噪循环

**做什么**：从纯噪声 `z_T ~ N(0, I)` 出发，逐步去噪得到 `z₀`。

**迭代形式**（以 DDPM 为例）：

```
for t = T, T-1, ..., 1:
    ε_θ = DiT(z_t, t, y)                    # 调用训练好的网络
    z_{t-1} = (1/√α_t) · (z_t - (β_t/√(1-ᾱ_t)) · ε_θ) + σ_t · z
```

**加速采样**：DDPM 需 1000 步，太慢。实际常用 **DDIM**、**DPM-Solver**、**Euler** 等，几十步甚至几步即可。DiT 论文报告用 250 步 DDIM 即可达到接近最优 FID。

**条件引导**：类别条件生成常用 **CFG（Classifier-Free Guidance）**，同时算有条件和不有条件两个预测，外推增强条件一致性：

```
ε = ε_uncond + w · (ε_cond - ε_uncond)
```

---

### 步骤 ⑥：VAE 解码 —— 回到像素空间

**做什么**：把去噪后的潜在 `z₀`（32×32×4）送入 VAE 解码器 `D`，重建为 256×256×3 的 RGB 图像。

**关键点**：

- 解码器同样冻结，不参与 DiT 训练。
- 最终图像质量 = DiT 去噪质量 × VAE 重建质量，二者缺一不可。
- 如果 VAE 重建有伪影或模糊，DiT 再强也无法弥补。

## 三、一句话总结每个步骤

| 步骤 | 名称 | 一句话作用 |
|------|------|-----------|
| ① | VAE 编码 | 把图像压到低维潜在空间，降低计算量 |
| ② | 前向加噪 | 随机采 t，构造带噪训练样本 |
| ③ | DiT 主干 | 用 Patchify + Transformer + AdaLN 预测噪声 |
| ④ | 计算损失 | MSE 衡量预测噪声与真实噪声差距 |
| ⑤ | 迭代去噪 | 从纯噪声逐步采样出干净潜在 |
| ⑥ | VAE 解码 | 把潜在还原成像素图像 |

## 四、与 U-Net 扩散模型流程的对比

| 环节 | U-Net 扩散（如 DDPM/SD1.5） | DiT |
|------|---------------------------|-----|
| 主干 | 卷积 + 下/上采样 + 跳连 | 纯 Transformer，无下采样 |
| 条件注入 | 交叉注意力 + 时间嵌入 | adaLN-Zero 调制 |
| 感受野 | 局部卷积逐层扩大 | 自注意力全局一步到位 |
| 缩放性 | 受 U-Net 结构限制 | 良好，可持续堆参数 |
| 计算复杂度 | 随分辨率线性/近似线性 | 随 Token 数平方增长 |
