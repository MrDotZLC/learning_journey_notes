## Diffusion模型
### 概念
Diffusion（扩散模型） 是一类生成模型，核心思想来自热力学中的扩散现象：先逐步给数据加噪声直到变成纯随机噪声，再训练模型学会把这个过程逆转，从噪声一步步还原出数据。

它和 GAN、VAE 并列为三大主流生成模型，但相比 GAN 训练更稳定、生成质量更高，是目前图像生成（Stable Diffusion、DALL·E、Midjourney）、视频生成、音频生成的主流方案。

Diffusion 推理就是"从一团随机噪声开始，让神经网络反复预测并减去噪声，逐步雕刻出一张图"的过程。

```
文本提示 → CLIP 文本编码器 → 文本 embedding
                              ↓
纯噪声 latent (64×64×4) → U-Net 反复去噪（cross-attention 注入文本条件）
                              ↓
                        VAE 解码器
                              ↓
                        512×512 图像
```
### U-Net 
在 Diffusion 中，它被用作**噪声预测网络** ε_θ(x_t, t)，是整个扩散模型的核心骨干。
#### 整体结构：编码器-解码器 + 跳跃连接
```
输入 x_t (H×W×C)
    │
┌───▼───┐  Down Block 1
│ Conv  │─────────────── skip ──────────────┐
│ Conv  │                                   │
└───┬───┘                                   │
    │ Downsample                            │
┌───▼───┐  Down Block 2                     │
│ Conv  │─────────────── skip ──────────┐   │
│ Conv  │                               │   │
└───┬───┘                               │   │
    │ Downsample                        │   │
┌───▼───┐  Down Block 3                 │   │
│ Conv  │─────────── skip ─────────┐    │   │
│ Conv  │                          │    │   │
└───┬───┘                          │    │   │
    │ Downsample                   │    │   │
┌───▼───────┐  Bottleneck          │    │   │
│ Conv+Attn │  (最低分辨率)         │    │   │
│ Conv+Attn │                      │    │   │
└───┬───────┘                      │    │   │
    │ Upsample                     │    │   │
┌───▼───┐  Up Block 3              │    │   │
│ Concat│◄─────────────────────────┘    │   │
│ Conv  │                               │   │
│ Conv  │                               │   │
└───┬───┘                               │   │
    │ Upsample                          │   │
┌───▼───┐  Up Block 2                   │   │
│ Concat│◄──────────────────────────────┘   │
│ Conv  │                                   │
│ Conv  │                                   │
└───┬───┘                                   │
    │ Upsample                              │
┌───▼───┐  Up Block 1                       │
│ Concat│◄──────────────────────────────────┘
│ Conv  │
│ Conv  │
└───┬───┘
    │
输出 ε_θ (H×W×C)  预测的噪声
```
**核心特点：**
- **下采样路径（Encoder）**：逐步降低空间分辨率，提取高层语义
- **上采样路径（Decoder）**：逐步恢复空间分辨率
- **跳跃连接（Skip Connection）**：把编码器同层特征直接拼接到解码器，保留细节信息
#### Diffusion U-Net 的关键组件
1. 残差块（ResNet Block）
	每个 Conv 层通常包在残差块里：
	```
	x → GroupNorm → SiLU → Conv → (+ time embedding) → GroupNorm → SiLU → Conv → + x
	```
	- 用 **GroupNorm** 而非 BatchNorm（对 batch size 不敏感）
	- 激活函数用 **SiLU / Swish**

2. 时间步嵌入（Time Embedding）
	因为同一个网络要处理所有 t，必须告诉它"现在是第几步"：
	```
	t → 正弦位置编码 → MLP → 每个 ResBlock 中注入（加法或 FiLM）
	```
	这相当于给网络一个"噪声程度"的条件信号。

3. 自注意力（Self-Attention）
	- 通常在**低分辨率层**（如 16×16、8×8）加入
	- 让远距离像素相互影响，捕捉全局结构
	- 高分辨率层用注意力太贵，所以只在瓶颈处用

4. 交叉注意力（Cross-Attention）—— Stable Diffusion 的关键
	在文本条件生成中，U-Net 每层插入：
	```
	Q = 图像特征
	K, V = 文本 embedding（来自 CLIP）
	Attention(Q, K, V)
	```
	这就是"文本控制图像"的机制——图像特征去"查询"文本信息。

### DiT (Diffusion Transformer)
旨在利用 Transformer 的可扩展性来提升生成性能，本质是个降噪器，沿用了 ViT 结构。
