## Diffusion模型
### 概念
Diffusion（扩散模型） 是一类生成模型，核心思想来自热力学中的扩散现象：先逐步给数据加噪声直到变成纯随机噪声，再训练模型学会把这个过程逆转，从噪声一步步还原出数据。

它和 GAN、VAE 并列为三大主流生成模型，但相比 GAN 训练更稳定、生成质量更高，是目前图像生成（Stable Diffusion、DALL·E、Midjourney）、视频生成、音频生成的主流方案。

Diffusion 推理就是"从一团随机噪声开始，让神经网络反复预测并减去噪声，逐步雕刻出一张图"的过程。

```
文本提示 → CLIP 文本编码器 → 文本 embedding
                              ↓
纯噪声 latent (64×64×4) → U-Net 反复去噪（cross-attention 注入文本条件）
                              ↓
                        VAE 解码器
                              ↓
                        512×512 图像
```
### U-Net 
在 Diffusion 中，它被用作**噪声预测网络** ε_θ(x_t, t)，是整个扩散模型的核心骨干。
#### 整体结构：编码器-解码器 + 跳跃连接
```
输入 x_t (H×W×C)
    │
┌───▼───┐  Down Block 1
│ Conv  │─────────────── skip ──────────────┐
│ Conv  │                                   │
└───┬───┘                                   │
    │ Downsample                            │
┌───▼───┐  Down Block 2                     │
│ Conv  │─────────────── skip ──────────┐   │
│ Conv  │                               │   │
└───┬───┘                               │   │
    │ Downsample                        │   │
┌───▼───┐  Down Block 3                 │   │
│ Conv  │─────────── skip ─────────┐    │   │
│ Conv  │                          │    │   │
└───┬───┘                          │    │   │
    │ Downsample                   │    │   │
┌───▼───────┐  Bottleneck          │    │   │
│ Conv+Attn │  (最低分辨率)         │    │   │
│ Conv+Attn │                      │    │   │
└───┬───────┘                      │    │   │
    │ Upsample                     │    │   │
┌───▼───┐  Up Block 3              │    │   │
│ Concat│◄─────────────────────────┘    │   │
│ Conv  │                               │   │
│ Conv  │                               │   │
└───┬───┘                               │   │
    │ Upsample                          │   │
┌───▼───┐  Up Block 2                   │   │
│ Concat│◄──────────────────────────────┘   │
│ Conv  │                                   │
│ Conv  │                                   │
└───┬───┘                                   │
    │ Upsample                              │
┌───▼───┐  Up Block 1                       │
│ Concat│◄──────────────────────────────────┘

│ Conv  │
└───┬───┘
    │
输出 ε_θ (H×W×C)  预测的噪声
```
**核心特点：**
- **下采样路径（Encoder）**：逐步降低空间分辨率，提取高层语义
- **上采样路径（Decoder）**：逐步恢复空间分辨率
- **跳跃连接（Skip Connection）**：把编码器同层特征直接拼接到解码器，保留细节信息
#### Diffusion U-Net 的关键组件
1. 残差块（ResNet Block）
	每个 Conv 层通常包在残差块里：
	```
	x → GroupNorm → SiLU → Conv → (+ time embedding) → GroupNorm → SiLU → Conv → + x
	```
	- 用 **GroupNorm** 而非 BatchNorm（对 batch size 不敏感）
	- 激活函数用 **SiLU / Swish**

2. 时间步嵌入（Time Embedding）
	因为同一个网络要处理所有 t，必须告诉它"现在是第几步"：
	```
	t → 正弦位置编码 → MLP → 每个 ResBlock 中注入（加法或 FiLM）
	```
	这相当于给网络一个"噪声程度"的条件信号。

3. 自注意力（Self-Attention）
	- 通常在**低分辨率层**（如 16×16、8×8）加入
	- 让远距离像素相互影响，捕捉全局结构
	- 高分辨率层用注意力太贵，所以只在瓶颈处用

4. 交叉注意力（Cross-Attention）—— Stable Diffusion 的关键
	在文本条件生成中，U-Net 每层插入：
	```
	Q = 图像特征
	K, V = 文本 embedding（来自 CLIP）
	Attention(Q, K, V)
	```
	这就是"文本控制图像"的机制——图像特征去"查询"文本信息。

### DiT (Diffusion Transformer)
旨在利用 Transformer 的可扩展性来提升生成性能，本质是个降噪器，沿用了 ViT 结构。
从纯高斯噪声逐步去噪生成一张符合文本或类别条件的图像。

```
[噪声向量 Z_T ~ N(0, I)]  +  [条件文本/类别标签 y]  +  [时间步 t]
          │
          ▼
┌────────────────────────────────────────────────────────┐
│  1. Latent Space & Patchification (潜空间与 Patch 化)   │
│     - 将噪声特征图切分成 Patch，并线性映射为 Token 序列    │
│     - 加入 1D 可学习的位置编码 (Position Embedding)      │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  2. Conditioning Processing (条件信息嵌入)              │
│     - 条件 y 与时间步 t 分别转为 Embedding               │
│     - 两者拼接/相加，生成全局条件向量 c                   │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  3. DiT Block Stack (Transformer 块循环去噪处理)         │
│     循环 N 层：                                         │
│     - AdaLN-Single / AdaLN-Zero：根据条件 c 预测缩放/   │
│       偏移参数 (γ, β, α) 并作用于 LayerNorm             │
│     - Multi-Head Self-Attention (自注意力机制)          │
│     - Pointwise Feed-Forward Network (前馈神经网络)     │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  4. Unpatchify (Token 还原为 Latent Feature)            │
│     - 预测噪声/速度向量 v_θ                              │
│     - 将 Token 序列恢复为 [C, H, W] 形状的特征图          │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  5. Sampling Update (采样算法更新迭代)                   │
│     - 根据 DDIM / DPM-Solver / Flow Matching 求解器     │
│     - 计算上一步特征 Z_{t-1}，循环 step 步直至 t = 0      │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  6. VAE Decoder Reconstruction (图像解码重建)           │
│     - 将去噪完成的 Latent 向量传入 VAE Decoder           │
│     - 还原为 RGB 高分辨率图像                            │
└────────────────────────────────────────────────────────┘
```

**推理步骤详解**

**1. 初始化与 Latent Patchification**

- **采样初始化**：从标准高斯分布 $\mathcal{N}(0, \mathbf{I})$ 中随机采样出一个初始噪声张量 $Z_T$，分辨率通常为潜空间大小（例如 $32 \times 32 \times 4$ 或 $64 \times 64 \times 4$）。
- **Patch 划分与线性投影**：将潜空间特征图 $Z_T \in \mathbb{R}^{C \times H \times W}$ 切分成无重叠的 Patch（如 $p \times p$ 块）。切分后的 Token 数量为 $N = (H/p) \times (W/p)$。接着通过一个 Linear 层（或卷积）将每个 Patch 映射为维度为 $D$ 的 Token 向量，得到大小为 $[N, D]$ 的序列。
- **位置编码**：将一维可学习的 1D Positional Embedding 叠加（Add）到 Patch Token 上，显式加入空间位置信息。

**2. 时间步与条件嵌入（Conditioning Embedding）**

- **时间步嵌入**：当前的去噪时间步 $t \in [0, T]$ 经过 频率/正弦 编码后，再通过两层 MLP 生成维度为 $D$ 的时间向量 $e_t$。
- **条件嵌入**：输入类别标签 $y$（或文本提示词通过 CLIP/T5 提取的特征向量）经过 Embedding 层后生成条件向量 $e_y$。
- **条件融合**：将 $e_t$ 和 $e_y$ 相加或拼接，通过 MLP 映射得到最终用于控制生成方向的全局条件向量 $c$。

**3. DiT Block 堆叠计算（核心主干）**

DiT 依靠堆叠的 Transformer Block 提取特征，其中核心关键是 **AdaLN-Zero (Adaptive Layer Normalization)** 条件注入机制：

- **预测调节参数**：全局条件向量 $c$ 传入 AdaLN 的 MLP 模块，动态预测出 6 个标量/向量参数： $(\gamma_1, \beta_1, \alpha_1, \gamma_2, \beta_2, \alpha_2)$。
- **自注意力机制（Self-Attention）**：输入 Token 首先经过 LayerNorm，并使用预测出的 $\gamma_1, \beta_1$ 进行按元素缩放与偏移：

    $$\text{AdaLN}(x) = \gamma_1 \odot \left(\frac{x - \mu}{\sigma}\right) + \beta_1$$
    
    接着计算多头自注意力（Self-Attention），输出结果乘以缩放因子 $\alpha_1$ 后通过残差连接（Residual Connection）加回原 Token。

- **前馈神经网络（FFN）**：Token 再次经过由 $\gamma_2, \beta_2$ 调控的 AdaLN，传入 MLP 模块，输出乘以 $\alpha_2$ 后同样通过残差连接叠加。

**4. Unpatchify（特征图重构）**

- **线性映射**：经过最后一个 DiT Block 后的 Token 序列再经过一层 Standard LayerNorm 和 Linear 投影层，将通道维度映射回 $p \times p \times C_{out}$（如果预测均值和方差，通道数为 $2C$）。
- **空间重组**：将维度为 $[N, p \times p \times C_{out}]$ 的向量序列重新拼回空间特征图维度 $[C_{out}, H, W]$，得到模型对当前时间步噪声或速度向量的预测结果。

**5. 采样器更新迭代（Sampling Loop）**

- **数值求解器**：拿到模型预测的噪声或速度向量后，利用采样算法（如 DDIM、DPM-Solver、Euler-Discrete 或 Flow Matching）计算前一步（$t-1$）更清晰的 Latent 特征 $Z_{t-1}$。
- **循环去噪**：将 $Z_{t-1}$ 作为新的输入，重新进入步骤 1-4。该循环重复 $K$ 次（通常为 20~50 步），直到获得时间步 $t=0$ 时的完全去噪特征向量 $Z_0$。

**6. VAE 解码生成图像**

- Latent 映射：将完全去噪后的潜空间特征 $Z_0$ 除以 VAE 的缩放系数（Scaling Factor）。
- **图像解码**：将特征输入预训练好的 VAE Decoder 神经网络进行上采样和特征解码，把 $H \times W$ 的 Latent 还原为 $fH \times fW$（例如 $512 \times 512$ 或 $1024 \times 1024$）的标准 RGB 图像。

### VEA 视频自编码器

**VEA（Video Encoder-Autoencoder / Video Autoencoder，视频自编码器）** 是构建 Latent Video Diffusion（潜空间视频扩散模型，如 Sora、CogVideoX、MAGVIT 等）的基础设施。

核心任务是“高倍率时空压缩与高质量像素重建”——把高维的原始视频像素，压缩到低维的潜空间（Latent Space），供扩散模型进行生成或编辑计算，最后再解码回高清视频。

#### 1. VEA 的核心设计思想

视频数据相比图像增加了时间维度（Time），数据量成倍暴增（例如一段 1080p@30fps 的 5 秒视频包含近 5GB 的原始 RGB 像素数据）。直接在像素空间运算会导致显存爆炸。

VEA 通过时空联合压缩（3D/Spatiotemporal Compression）来解决这一痛点：

|**维度**|**像素空间 (Pixel Space)**|**潜空间 (Latent Space)**|**典型压缩倍率**|
|---|---|---|---|
|**空间 (H, W)**|$1080 \times 1920$|$135 \times 240$|$8 \times 8$ (Spatial Downsampling)|
|**时间 (T)**|$16$ 帧|$4$ 帧|$4 \times$ (Temporal Downsampling)|
|**通道 (C)**|$3$ (RGB)|$4 \sim 16$|提炼为高阶语义/时空特征|

#### 2. VEA 网络架构与三大核心模块
VEA 的标准架构建立在 **3D-VAE (Variational Autoencoder)** 或 **3D-VQGAN** 结构之上，主要包含以下三个核心部分：
  
```
[ 原始视频帧 X ] ──► [ 3D Encoder ] ──► [ 潜空间正则化 / 量化 ] ──► [ 潜特征 Latent Z ]
                                                                      │
[ 重建视频帧 X' ] ◄── [ 3D Decoder ] ◄────────────────────────────────┘
```

### ① 3D 编码器 (3D Encoder)
- **原理**：输入形状为 $(B, C, T, H, W)$ 的视频张量。通过 **3D 卷积（3D-Conv）** 或 **时空注意力机制（Swin 3D Transformer / Causal Attention）**，同时在空间方向（上下左右）和时间方向（前后帧）提取局部与全局的帧间关联。
- **因果卷积（Causal Convolution）**：现代 VEA 普遍引入因果机制（即当前帧的编码仅依赖于过去的帧，不依赖未来的帧），使得 VEA 可以支持任意长度视频的流式（Streaming）编码与生成。

### ② 潜空间正则化 (Latent Bottleneck & Regularization)
为了避免 Encoder 生成的 Latent 过度任意，方便后续扩散模型对 Latent 进行噪声建模，需要对 Latent 施加约束：
- **KL-VAE 方式**：将编码结果映射为均值 $\mu$ 与方差 $\sigma$，添加 KL 散度损失，使 Latent 服从标准高斯分布 $\mathcal{N}(0, \mathbf{I})$。
- **VQ/FSQ 方式**：将连续 Latent 量化为离散 Codebook 中的 Vector，提高重建的边缘清晰度。

### ③ 3D 解码器 (3D Decoder)
- **原理**：将压缩后的 Latent $Z$ 还原为 RGB 视频。结构与 Encoder 对称，采用 3D 转置卷积（3D Deconvolution）或时空上采样模块。
- **时空对齐与平滑**：Decoder 需要在重建图像纹理细节的同时，保障相邻帧解码结果的连续性，消除画面抖动（Flicker）。

## 3. VEA 的关键技术突破点

### 1) 3D 因果注意力与卷积 (Causal 3D Architecture)
传统的 3D 卷积在时间维度的 padding 是双向的（同时参考前后帧），这会导致长视频无法分段解码。**因果 3D 结构（Causal 3D）** 保证了首帧独立编码，后续帧顺次扩展，使得 VEA 能够以极低显存无缝拼接长视频。

### 2) 感知损失与对抗损失 (Perceptual & GAN Loss)
为了防止高倍率压缩导致视频变糊，VEA 在训练时结合了多重 Loss：
- **重构损失 ($L_1 / L_2$)**：保障总体颜色与像素对应。
- **感知损失 (LPIPS)**：利用预训练网络提取特征，保障纹理符合人类视觉习惯。
- **3D 鉴别器 (3D PatchGAN Discriminator)**：引入对抗训练，对生成的视频进行“真实度”打分，大幅提升视频的动态细节（如水流、火焰、毛发）。

### 3) 跨帧缓存与滑动窗口 (Tiling & Temporal Caching)
在实际推理阶段（Inference），由于显存限制，VEA 解码器会采用 **Temporal Tiling** 策略：将长视频 Latent 切分为小块（Tile），重叠部分采用权重平滑过渡（Overlap Blending），从而实现无缝解码超长或超高分辨率视频。

## 4. VEA 在视频扩散模型中的实际应用
在复杂的视频生成系统（如 T2V / I2V）中，VEA 扮演着“视频空间转换器”的角色：
1. **训练阶段**：用预训练好的 **VEA Encoder** 把海量训练视频转为 Latent，所有的 Diffusion 模型（DiT/UNet）只针对低维 Latent 计算 Gradient，计算资源消耗降低 90% 以上。
2. **推理阶段**：DiT 经过多步采样去噪得到一个干净的视频 Latent 后，最终调用 **VEA Decoder** 一次性解码出高清视频。
