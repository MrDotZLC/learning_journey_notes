## **一、概述**
在大模型推理中，计算量大、显存占用高、内存带宽瓶颈明显。为提升推理性能，主要采用以下三种优化技术：
1. **QKV Matmul** – 合并 Q/K/V 投影矩阵乘法，减少算子调用和内存访问。
2. **Fused Kernel** – 将多个小算子融合在单个 GPU kernel 内，降低 kernel launch 和 global memory 访问。
3. **FlashAttention** – 重写注意力计算算法，使用分块 + 在线 softmax，降低显存占用，提升长序列性能。
## **二、QKV Matmul**
### **1. 目标**
- 在 Transformer Attention 中生成 Q、K、V 向量。
- 原本需要做三次 GEMM（矩阵乘法），每次读 X → W → 写输出 → 带宽消耗大。
- 合并成一次 GEMM，输出 `[B, L, 3H]`，再 split 为 Q/K/V。
### **2. 优化方法**
- 将权重 `Wq, Wk, Wv` 拼接为 `W_qkv`（shape `[H, 3H]`）。
- 一次 GEMM：`X @ W_qkv → [B, L, 3H]`
- CUDA 实现：
    - 使用 **cuBLAS / cublasLtGemm** 或 **Triton 自定义 kernel**
    - 支持 tile/block 分块处理，适合张量并行（TP）
    - 可直接融合 RoPE、Bias、Rescale 等操作
### **3. 优势**
- GEMM 数量从 3 → 1
- 内存访问减少约 3 倍
- kernel launch 减少 2 次
- 显存占用降低
### **4. 层级**
- **算子级优化（Operator-level）**
- 在推理流程中对应 **Q/K/V Linear Projection 步骤**
## **三、Fused Kernel**
### **1. 目标**
- 大模型每层有很多小算子：LayerNorm、Bias、GELU、Residual Add、Linear 等。
- 每个独立 kernel 会频繁访问 global memory，kernel launch overhead 高。
- 通过融合算子在一个 kernel 内执行，减少内存访问和 kernel launch。
### **2. 实现方法**
- **寄存器流水线**：中间结果在寄存器或 SMEM 内传递
- **Shared Memory Buffer**：Tile block 内计算，跨 warp 协作
- **Warp-level GEMM / TensorCore**：利用 Tensor Core 提升吞吐
- **Double Buffering**：加载下一块数据同时计算当前块
### **3. 融合示例**

| 融合算子                                 | 功能                   |
| ------------------------------------ | -------------------- |
| LayerNorm + Residual Add             | 避免中间读写 global memory |
| GEMM + GELU + GEMM（MLP）              | Fused MLP kernel     |
| QKV + Bias + RoPE                    | Fused QKV kernel     |
| Attention Mask + Softmax + MatMul(V) | 可结合 FlashAttention   |

### **4. 优势**
- 内存访问减少
- kernel launch 减少
- 提升 GPU 利用率和推理吞吐
### **5. 层级**
- **算子级 / GPU kernel 级优化**
- 对应 **LayerNorm、MLP、Residual、Bias 等小算子**
## **四、FlashAttention**
### **1. 目标**
- 原始 Attention：
    `A = softmax(Q @ K^T / √d) @ V`
    - 需要存储 L×L 矩阵，显存 O(L²)
    - 长序列时显存爆炸，带宽瓶颈严重
- FlashAttention 通过 **分块 + 在线 softmax** 重写算法
    - 显存占用降为 O(L×H)
    - 速度提升，特别是长序列推理
### **2. 实现方法**
1. 将 Q 分成行块（tile），K/V 分成列块
2. 在 **SMEM / registers** 内计算 `Q_tile @ K_tile^T`
3. 在线 softmax：
    - 分块计算 max、sum
    - 合并到全局结果
4. 直接乘 V_tile，累加输出
5. 不生成完整 L×L 矩阵
6. 支持 causal mask（自回归推理）
### **3. 优势**
- 显存占用从 O(L²) → O(L×H)
- 内存带宽消耗降低
- 可支持长序列推理（8k、32k、128k）
### **4. 层级**
- **算法级优化 + kernel 实现优化**
- 对应 **Attention 层（Softmax + QK^T @ V）**
## **五、三种技术在推理流程中的位置**

```
输入 Embedding / 上一层输出
↓ LayerNorm
↓ Q/K/V Linear Projection (QKV Matmul)
↓ (可选 RoPE)
↓ Attention (Softmax + MatMul V) (FlashAttention)
↓ Residual Add
↓ LayerNorm
↓ MLP (GEMM1 → GELU → GEMM2) (Fused Kernel)
↓ Residual Add
↓ 输出到下一层
```
### 层级总结

|技术|优化层级|对应步骤|
|---|---|---|
|QKV Matmul|算子级|Q/K/V Linear Projection|
|Fused Kernel|GPU kernel 级|LayerNorm、MLP、Residual Add 等小算子|
|FlashAttention|算法级 + kernel|Attention 层 Softmax + QK^T @ V|

---

### **六、总结**

- **QKV Matmul** → 合并 Q/K/V 投影矩阵乘法，减少算子调用和内存访问
- **Fused Kernel** → 多小算子融合在单个 kernel 内，减少 global memory 读写和 kernel launch
- **FlashAttention** → Attention 分块 + 在线 softmax，减少显存占用并加速长序列推理

三者结合，是现代大模型推理性能优化的核心手段。
