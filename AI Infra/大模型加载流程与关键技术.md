# 大模型加载流程
## 一、整体加载流程
### 1️⃣ 解析配置（Config）
**操作**:
```python
from transformers import AutoConfig
config = AutoConfig.from_pretrained("model_path")
```
**作用 / 原因**:
- 获取模型结构信息（层数、隐藏维度、头数、词表大小）
- 估算显存和 RAM 占用
- 规划 KV Cache 大小和 device_map
**实践**:
- 提前解析 config 可决定是否使用 meta tensor / lazy init
### 2️⃣ 构建模型结构（实例化模型）
**操作**:
```python
from transformers import AutoModelForCausalLM
model = AutoModelForCausalLM.from_config(config)
```
或使用 Lazy Init:
```python
from accelerate import init_empty_weights
with init_empty_weights():
    model = AutoModelForCausalLM.from_config(config)
```
**作用 / 原因**:
- 根据 config 构建模型层级
- Lazy Init 不分配显存，避免 OOM
**实践**:
- 对大模型 (>10B) 必须使用 lazy init
### 3️⃣ 准备权重文件
**形式**:
- 单文件 checkpoint（小模型 <10B）
- Sharded Checkpoint（大模型）
```text
pytorch_model-00001-of-00005.bin
pytorch_model-00002-of-00005.bin
```
**作用 / 原因**:
- 避免一次性加载整个模型到 RAM / GPU
- 支持多 GPU / CPU Offload
### 4️⃣ 权重加载
**操作**:
```python
state_dict = torch.load("pytorch_model-00001-of-00005.bin", mmap_mode="r")
model.load_state_dict(state_dict, strict=False)
```
**作用 / 原因**:
- mmap 按需加载，减少 RAM 使用
- 可以结合 Lazy Init 按 shard 加载到 GPU
- 支持量化 / AMP[量化与AMP](../Transformer/量化与AMP.md)
**实践**:
- 量化模型必须结合 no_grad 使用
- device_map 自动分配权重到设备
### 5️⃣ 权重分配到设备
**操作**:
```python
model = AutoModelForCausalLM.from_pretrained(
    "model_path",
    device_map="auto",
    offload_folder="offload",
)
```
**作用 / 原因**:
- 单 GPU 显存不足时分配到多 GPU 或 CPU
- KV Cache 分配，避免重复计算
### 6️⃣ 校验权重
**操作**:
```python
missing_keys, unexpected_keys = model.load_state_dict(state_dict, strict=False)
```
**作用 / 原因**:
- 确保权重与模型结构匹配，避免 NaN
- 提前发现 shard 文件加载错误
### 7️⃣ 推理前准备
**操作**:
```python
model.eval()
torch.set_grad_enabled(False)
inputs = tokenizer("Hello world", return_tensors="pt").to(model.device)
```
**作用 / 原因**:
- `eval()` 关闭 dropout / BatchNorm 更新
- `no_grad()` 禁用梯度计算，释放显存
- Tokenizer 准备输入 tensor 并移到设备
- KV Cache 初始化
### 8️⃣ 进入推理模式
**操作**:
```python
with torch.no_grad():
    with torch.cuda.amp.autocast(dtype=torch.bfloat16):
        outputs = model.generate(inputs, max_new_tokens=50, use_cache=True)
```
**作用 / 原因**:
- AMP / BF16 提升推理速度，降低显存
- use_cache=True 开启 KV cache，自回归生成加速
- no_grad + eval 确保显存最优和推理稳定
### 9️⃣ 关键技术总结

| 技术                      | 作用             | 优势             | 注意事项                      |
| ----------------------- | -------------- | -------------- | ------------------------- |
| Lazy Init / Meta Tensor | 构建结构不占显存       | 支持超大模型         | 自定义层 shape 推断难，多 GPU 分配复杂 |
| Sharded Checkpoint      | 权重按文件 / GPU 分片 | 支持多 GPU & 并行加载 | 文件多，分布式恢复复杂               |
| mmap                    | 权重按需从磁盘映射      | RAM 占用低，支持大模型  | 随机访问慢，依赖磁盘性能              |
| AMP / BF16 / FP16       | 加速 + 节省显存      | 推理速度快          | 需结合 no_grad 使用            |
| 量化 (8/4 bit)            | 节省显存           | 支持更大模型         | 需关闭梯度，KV cache 占用依旧       |
### 1️⃣0️⃣ 完整加载示例

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM

torch.set_grad_enabled(False)

# Tokenizer
tokenizer = AutoTokenizer.from_pretrained("model_path")
if tokenizer.pad_token is None:
    tokenizer.add_special_tokens({'pad_token': '[PAD]'})

# 模型加载
model = AutoModelForCausalLM.from_pretrained(
    "model_path",
    device_map="auto",
    torch_dtype=torch.bfloat16,
    low_cpu_mem_usage=True,
)
model.eval()

# 输入准备
inputs = tokenizer("Hello world", return_tensors="pt").to(model.device)

# 推理
with torch.no_grad():
    with torch.cuda.amp.autocast(dtype=torch.bfloat16):
        outputs = model.generate(inputs, max_new_tokens=50, use_cache=True)

# 输出解码
text = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(text)
```
## 六、操作名 & 缩写解释

| 名称 / 缩写                     | 全称 / 中文                   | 简单解释                         | 适用场景 / 备注                 |
| --------------------------- | ------------------------- | ---------------------------- | ------------------------- |
| Config                      | Configuration             | 模型配置文件，包含层数、隐藏维度、注意力头数、词表大小等 | 初始化模型结构                   |
| Meta Tensor / Lazy Init     | 元张量 / 延迟初始化               | 创建张量占位符，不分配显存                | 初始化超大模型                   |
| Sharded Checkpoint          | 分片权重文件                    | 将模型权重拆分成多个文件或按设备分片           | 多 GPU / 大模型加载             |
| mmap                        | Memory Mapping（内存映射）      | 权重按需从磁盘映射到虚拟内存               | 避免一次性读入 RAM，支持超大模型        |
| AMP                         | Automatic Mixed Precision | 自动混合精度（FP16 / BF16 + FP32）   | GPU 推理加速 + 节省显存           |
| BF16 / FP16                 | Brain Float 16 / Float 16 | 半精度浮点数                       | 用于 AMP / 推理加速             |
| INT8 / INT4                 | 8位 / 4位整数                 | 权重量化表示                       | 节省显存、加速推理                 |
| KV Cache                    | Key-Value Cache           | 注意力缓存，存储前文 key/value         | 自回归生成加速，避免重复计算            |
| device_map                  | 设备映射                      | 指定模型每层放置到哪个 GPU / CPU        | 多 GPU / CPU Offload 使用    |
| CPU Offload                 |                           | 将部分权重放到 CPU                  | 单 GPU 显存不足                |
| eval()                      | Evaluation Mode           | 模型推理模式                       | 关闭 dropout / BatchNorm 更新 |
| no_grad()                   | 禁用梯度                      | 不构建计算图，不保存中间激活               | 推理必用，节省显存                 |
| low_cpu_mem_usage           | 低 CPU 内存占用                | Transformers 提供的加载优化         | 结合 Lazy Init / mmap 使用    |
| load_in_4bit / load_in_8bit | 4位 / 8位量化加载               | 权重量化加载                       | 节省显存，加速推理                 |
| Tokenizer                   | 分词器                       | 将文本转为 token id               | 推理 / 训练输入处理               |
| max_new_tokens              | 最大生成长度                    | 控制生成序列长度                     | 自回归生成使用                   |
| use_cache=True              | 使用 KV Cache               | 开启注意力缓存                      | 自回归生成加速                   |
| strict=False                | 非严格加载                     | 忽略 missing / unexpected keys | shard 或量化模型加载时常用          |
