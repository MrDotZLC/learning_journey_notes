## 梯度稳定性问题

### 1. 梯度消失（Gradient Vanishing）

#### 1.1 定义

反向传播中，梯度经链式法则逐层相乘。若每层的局部梯度 $|\partial z^{(l)} / \partial z^{(l-1)}| < 1$，则梯度随层数 $L$ 指数衰减，趋近于零，导致浅层参数几乎不更新。

#### 1.2 发生场景

|场景|原因|
|---|---|
|深层 MLP / CNN|链式乘积层数过深|
|Sigmoid / Tanh 激活|导数值域有界且 $< 1$|
|Vanilla RNN（长序列）|时间步展开等价于极深网络|
|权重初始化过小|前向传播特征值缩小，反向梯度同步缩小|

#### 1.3 数学推导

以 $L$ 层全连接网络为例，损失 $\mathcal{L}$ 对第 $1$ 层参数 $W^{(1)}$ 的梯度：

$$\frac{\partial \mathcal{L}}{\partial W^{(1)}} = \frac{\partial \mathcal{L}}{\partial z^{(L)}} \cdot \prod_{l=2}^{L} \frac{\partial z^{(l)}}{\partial z^{(l-1)}} \cdot \frac{\partial z^{(1)}}{\partial W^{(1)}}$$

其中每个因子：

$$\frac{\partial z^{(l)}}{\partial z^{(l-1)}} = W^{(l)} \cdot \text{diag}!\left(\sigma'!\left(z^{(l-1)}\right)\right)$$

若使用 Sigmoid，其导数满足：

$$\sigma'(x) = \sigma(x)(1 - \sigma(x)) \leq \frac{1}{4}$$

代入得上界估计：

$$\left| \frac{\partial \mathcal{L}}{\partial W^{(1)}} \right| \leq \left| \frac{\partial \mathcal{L}}{\partial z^{(L)}} \right| \cdot \prod_{l=2}^{L} \left| W^{(l)} \right| \cdot \left(\frac{1}{4}\right)^{L-1}$$

对 $L = 50$ 层：$(1/4)^{49} \approx 1.78 \times 10^{-30}$，已完全淹没在浮点精度误差中。

#### 1.4 RNN 中的特殊性

RNN 时间步展开后，梯度对时刻 $t=1$ 的传播路径长度等于序列长度 $T$：

$$\frac{\partial \mathcal{L}}{\partial h_1} = \prod_{t=2}^{T} \frac{\partial h_t}{\partial h_{t-1}} = \prod_{t=2}^{T} W_h \cdot \text{diag}(\sigma'(h_{t-1}))$$

若 $W_h$ 的谱范数 $\rho(W_h) < 1$，则梯度指数消失；若 $\rho(W_h) > 1$，则梯度爆炸。两种情况均使长期依赖无法学习，实践中 Vanilla RNN 有效记忆通常不超过 10–20 步。

#### 1.5 Transformer 为何天然缓解长程梯度消失

Vanilla RNN 中，时刻 $t=1$ 的梯度必须经过 $T-1$ 次矩阵乘法：

$$\frac{\partial h_T}{\partial h_1} = \prod_{t=2}^{T} W_h \cdot \text{diag}(\sigma'(h_{t-1}))$$

Self-Attention 中，任意两个 token 之间存在**直接的注意力连接**，梯度路径长度恒为 $O(1)$：

$$\text{Attention}(Q, K, V) = \text{softmax}!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

token $i$ 对 token $j$ 的直接梯度路径为 $\mathcal{L} \to \text{output}_i \to V_j \to h_j$，无中间递归连乘。这是 Transformer 能处理数千 token 长序列而 Vanilla RNN 不能的根本原因。

### 2. 梯度爆炸（Gradient Exploding）

#### 2.1 定义

链式法则中，若每层局部梯度 $> 1$，则梯度随层数指数增长，参数更新量超出合理范围，使模型发散。

#### 2.2 发生场景

|场景|原因|
|---|---|
|深层 RNN（长序列）|Jacobian 矩阵连乘，谱范数 $> 1$|
|权重初始化过大|前向传播方差放大，反向梯度同步放大|
|ReLU + 坏初始化|正区间梯度恒为 1，权重矩阵本身放大信号|

#### 2.3 数学推导

以 $|W^{(l)}| = 1.5$，$L = 50$：

$$(1.5)^{49} \approx 6.37 \times 10^{9}$$

单次参数更新量 $\Delta W = -\eta \cdot \nabla W$，若 $\eta = 10^{-3}$，则更新量 $\approx 10^{6}$，远超参数自身量级，Loss 直接变 NaN。

#### 2.4 梯度消失 vs 梯度爆炸对比

|对比项|梯度消失|梯度爆炸|
|---|---|---|
|触发条件|链式乘积 $< 1$|链式乘积 $> 1$|
|典型激活函数|Sigmoid / Tanh|ReLU（坏初始化）|
|主要症状|前层不更新，训练停滞|Loss 变 NaN，参数爆炸|
|重灾区|深层 MLP、RNN|深层 RNN|
|核心解法|残差连接、ReLU、LN|梯度裁剪、LSTM/GRU|

### 3. 梯度裁剪（Gradient Clipping）

#### 3.1 Clip by Norm（主流方案）

设全局梯度范数：

$$g = \left|\nabla_\theta \mathcal{L}\right|_2 = \sqrt{\sum_i \left(\frac{\partial \mathcal{L}}{\partial \theta_i}\right)^2}$$

若 $g > g_{\max}$，则等比例缩放：

$$\nabla_\theta \mathcal{L} \leftarrow \frac{g_{\max}}{g} \cdot \nabla_\theta \mathcal{L}$$

缩放后**方向不变**，仅控制步长幅度。$g_{\max}$ 典型取值：RNN 训练取 $1.0$–$5.0$，LLM 训练（如 LLaMA）取 $1.0$。

```cpp
// libtorch C++
torch::nn::utils::clip_grad_norm_(model->parameters(), /*max_norm=*/1.0);
```

#### 3.2 Clip by Value（不推荐）

$$\nabla_\theta \leftarrow \text{clip}(\nabla_\theta,\ -c,\ +c)$$

逐元素截断，**破坏梯度方向**，仅用于极端情况的兜底保护。

#### 3.3 梯度 Norm 监控实践

训练健康度可通过梯度 norm 曲线判断：

|曲线形态|含义|处理建议|
|---|---|---|
|平稳下降后趋于稳定|正常收敛|无需干预|
|持续接近 $g_{\max}$（频繁触发裁剪）|学习率过大或结构问题|降低学习率|
|突然尖峰（Loss spike）|异常 batch 或优化器状态损坏|检查数据，考虑跳过该 batch|
|持续趋近于 $0$|梯度消失，前层停止学习|检查激活函数和初始化|

LLM 训练中通常在 wandb / TensorBoard 中记录 `grad_norm` 曲线，连续 spike 是调低学习率或检查数据质量的信号。

### 4. 激活函数与梯度稳定性

#### 4.1 Sigmoid 与 Tanh 的问题根源

**Sigmoid**：

$$\sigma(x) = \frac{1}{1 + e^{-x}}, \quad \sigma'(x) = \sigma(x)(1-\sigma(x)) \in (0,\ 0.25]$$

**Tanh**：

$$\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}, \quad \tanh'(x) = 1 - \tanh^2(x) \in (0,\ 1]$$

两者共同问题：

- 饱和区（$|x|$ 较大时）导数趋近于 $0$，梯度消失
- Sigmoid 输出范围 $(0, 1)$，非零均值，导致下游权重梯度方向受限（zigzag 问题）
- Tanh 虽零均值，但饱和区同样存在梯度消失

#### 4.2 ReLU

$$\text{ReLU}(x) = \max(0,\ x), \quad \text{ReLU}'(x) = \begin{cases} 1 & x > 0 \ 0 & x \leq 0 \end{cases}$$

正区间梯度恒为 $1$，彻底解决链式乘积缩小问题。50 层网络中若所有神经元均处于激活状态：

$$\prod_{l=1}^{50} \text{ReLU}'(z^{(l)}) = 1^{50} = 1$$

**局限 — 死亡 ReLU（Dying ReLU）**：

负区间导数为 $0$。若某神经元的输入在训练中持续为负，则该神经元输出恒为 $0$，梯度恒为 $0$，**永久失活**，无法被任何后续梯度复活。

判定条件：对所有训练样本 $x$，若 $W x + b < 0$ 恒成立，则该神经元死亡。

触发原因：初始化权重过大导致负偏，或学习率过大使权重在一次更新后跳至极端负值。大模型中死亡 ReLU 导致的神经元稀疏性可达 $30\%$–$50\%$，这是 LLM 转向 SiLU / GELU 的主要原因之一。

#### 4.3 GELU（Gaussian Error Linear Unit）

$$\text{GELU}(x) = x \cdot \Phi(x) = x \cdot \frac{1}{2}\left[1 + \text{erf}!\left(\frac{x}{\sqrt{2}}\right)\right]$$

其中 $\Phi(x)$ 为标准正态分布的 CDF，$\text{erf}$ 为误差函数。

**直觉**：$x$ 被保留的概率为 $\Phi(x)$，即越大的输入越大概率通过，负区间有小幅抑制而非硬截断。

实用近似（避免 $\text{erf}$ 计算开销）：

$$\text{GELU}(x) \approx 0.5x!\left(1 + \tanh!\left(\sqrt{\frac{2}{\pi}}\left(x + 0.044715x^3\right)\right)\right)$$

导数（精确形式）：

$$\text{GELU}'(x) = \Phi(x) + x \cdot \phi(x)$$

其中 $\phi(x) = \frac{1}{\sqrt{2\pi}} e^{-x^2/2}$ 为标准正态 PDF。

**特性**：

- 负区间梯度不完全为零，平滑过渡，避免死亡神经元
- 输出均值接近零，统计特性好
- 计算开销高于 ReLU（含 $\text{erf}$ 或 $\tanh$ 近似）
- BERT、GPT 系列均使用 GELU

#### 4.4 SiLU（Sigmoid Linear Unit / Swish）

$$\text{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$

导数：

$$\text{SiLU}'(x) = \sigma(x) + x \cdot \sigma(x)(1 - \sigma(x)) = \sigma(x)\left(1 + x(1 - \sigma(x))\right)$$

**特性**：

- 非单调：负区间有小幅负值输出，保留部分负区间信息
- 全域梯度连续且非零，完全避免死亡神经元
- 计算量低于 GELU（无需 $\text{erf}$，仅需一次 Sigmoid）
- LLaMA、Mistral、Qwen 的 FFN 层均使用 SiLU，配合 SwiGLU 门控结构

**SwiGLU（SiLU + GLU 门控）**：

$$\text{SwiGLU}(x, W, V) = \text{SiLU}(xW) \odot (xV)$$

LLaMA FFN 层的完整结构：

$$\text{FFN}(x) = \text{SwiGLU}(x, W_1, W_3) \cdot W_2$$

两个并行线性投影（$W_1$、$W_3$）的输出逐元素相乘后再投影，增强了 FFN 的表达能力。

#### 4.5 激活函数对比

|特性|Sigmoid|Tanh|ReLU|GELU|SiLU|
|---|---|---|---|---|---|
|输出范围|$(0, 1)$|$(-1, 1)$|$[0, +\infty)$|$\approx(-0.17, +\infty)$|$\approx(-0.28, +\infty)$|
|正区间导数|$\leq 0.25$|$\leq 1$|恒为 $1$|$> 0$|$> 0$|
|负区间导数|$\approx 0$（饱和）|$\approx 0$（饱和）|恒为 $0$|小正值|小正/负值|
|死亡神经元|否（但饱和）|否（但饱和）|**是**|否|否|
|零均值输出|否|是|否|近似是|近似是|
|计算开销|中|中|低|高（含 erf）|中|
|主要应用|早期 MLP、输出层|历史 RNN|历史 CNN|BERT、GPT|LLaMA、Qwen|

### 5. LSTM / GRU 门控机制

#### 5.1 Vanilla RNN 的梯度问题回顾

Vanilla RNN 隐状态更新：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

梯度路径完全依赖连乘 $\prod W_h \cdot \text{diag}(\tanh'(\cdot))$，无任何捷径。

#### 5.2 LSTM（Long Short-Term Memory）

LSTM 引入**细胞状态** $c_t$ 作为独立信息高速通道，通过三个门控制信息流。

**遗忘门**（决定丢弃多少历史信息）：

$$f_t = \sigma(W_f [h_{t-1},\ x_t] + b_f)$$

**输入门**（决定写入多少新信息）：

$$i_t = \sigma(W_i [h_{t-1},\ x_t] + b_i)$$

**候选细胞状态**（新信息的内容）：

$$\tilde{c}_t = \tanh(W_c [h_{t-1},\ x_t] + b_c)$$

**细胞状态更新**：

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$

**输出门**：

$$o_t = \sigma(W_o [h_{t-1},\ x_t] + b_o), \quad h_t = o_t \odot \tanh(c_t)$$

**梯度流动分析**：

$c_t$ 对 $c_{t-1}$ 的梯度：

$$\frac{\partial c_t}{\partial c_{t-1}} = f_t$$

$f_t \in (0, 1)$ 是**可学习的逐元素乘法**，不是固定矩阵乘法。当遗忘门 $f_t \approx 1$ 时：

$$\frac{\partial \mathcal{L}}{\partial c_1} \approx \frac{\partial \mathcal{L}}{\partial c_T} \cdot \prod_{t=2}^{T} f_t \approx \frac{\partial \mathcal{L}}{\partial c_T}$$

梯度几乎无衰减地流回 $c_1$。与 Vanilla RNN 的固定矩阵连乘相比，LSTM 的梯度路径是**自适应调节的**——网络学习令重要信息的梯度畅通，令无关信息的梯度截断。

#### 5.3 GRU（Gated Recurrent Unit）

GRU 将 LSTM 的三个门简化为两个，取消独立细胞状态。

**重置门**（决定忘记多少历史）：

$$r_t = \sigma(W_r [h_{t-1},\ x_t] + b_r)$$

**更新门**（决定保留多少历史 vs 写入新信息）：

$$z_t = \sigma(W_z [h_{t-1},\ x_t] + b_z)$$

**候选隐状态**：

$$\tilde{h}_t = \tanh(W_h [r_t \odot h_{t-1},\ x_t] + b_h)$$

**隐状态更新**：

$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

梯度对 $h_{t-1}$ 的路径：

$$\frac{\partial h_t}{\partial h_{t-1}} = (1 - z_t) + z_t \cdot \frac{\partial \tilde{h}_t}{\partial h_{t-1}}$$

恒等项 $(1 - z_t)$ 的作用与残差连接中的 $1$ 完全类似：当 $z_t \approx 0$ 时，$h_t \approx h_{t-1}$，梯度直接流过不衰减。

#### 5.4 LSTM vs GRU 对比

|对比项|LSTM|GRU|
|---|---|---|
|门数量|3（遗忘、输入、输出）|2（重置、更新）|
|独立细胞状态|有（$c_t$）|无（$h_t$ 兼任）|
|参数量|较多（约 GRU 的 $4/3$）|较少|
|长序列表现|略优（细胞状态保护更强）|相当|
|现代使用场景|序列标注、语音|轻量级序列任务|

Transformer 出现后，LSTM / GRU 在 NLP 主流任务中已基本被取代，但在边缘设备、流式处理等低延迟场景仍有应用。

### 6. 解决方案汇总

|方案|解决问题|作用机制|
|---|---|---|
|ReLU / GELU / SiLU|梯度消失|正区间梯度为常数或非零，不衰减|
|残差连接|梯度消失|梯度有恒等捷径路径，详见 [[残差连接（Residual Connection）]]|
|LayerNorm / RMSNorm|梯度消失/爆炸|控制激活值分布，避免进入饱和区|
|LSTM / GRU|RNN 梯度消失/爆炸|门控机制提供自适应梯度路径|
|梯度裁剪|梯度爆炸|控制更新步长上界，保持方向|
|Xavier / Kaiming 初始化|梯度消失/爆炸|使各层输出方差近似一致|
|Transformer Self-Attention|长程梯度消失|token 间直接路径，梯度路径长度 $O(1)$|

### 7. 权重初始化（Weight Initialization）

#### 7.1 动机

初始化直接决定训练早期各层输出的方差。若方差逐层缩小则梯度消失，逐层放大则梯度爆炸。目标是使每层输出方差与输入方差保持一致，从源头控制梯度稳定性。

#### 7.2 Xavier 初始化（Glorot Initialization）

适用于 **Sigmoid / Tanh** 激活函数。

设 $W \in \mathbb{R}^{n_{\text{out}} \times n_{\text{in}}}$，$x \in \mathbb{R}^{n_{\text{in}}}$ 各分量独立且均值为 $0$，$W$ 各元素独立且均值为 $0$。

**前向传播方差分析**：

$$y_j = \sum_{k=1}^{n_{\text{in}}} W_{jk} x_k \implies \text{Var}(y_j) = n_{\text{in}} \cdot \text{Var}(W) \cdot \text{Var}(x)$$

令 $\text{Var}(y) = \text{Var}(x)$，得前向条件：$\text{Var}(W) = 1 / n_{\text{in}}$

**反向传播方差分析**：

$$\delta^{(l-1)}_k = \sum_{j} W_{jk} \cdot \delta^{(l)}_j \implies \text{Var}(\delta^{(l-1)}) = n_{\text{out}} \cdot \text{Var}(W) \cdot \text{Var}(\delta^{(l)})$$

令前后层梯度方差一致，得反向条件：$\text{Var}(W) = 1 / n_{\text{out}}$

**调和平均综合两个条件**：

$$\text{Var}(W) = \frac{2}{n_{\text{in}} + n_{\text{out}}}$$

均匀分布采样：$W \sim \mathcal{U}!\left[-\sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}},\ +\sqrt{\frac{6}{n_{\text{in}} + n_{\text{out}}}}\right]$

#### 7.3 Kaiming 初始化（He Initialization）

适用于 **ReLU / GELU / SiLU** 激活函数。

ReLU 将约一半输入置零，使输出方差减半。设激活前 $y \sim \mathcal{N}(0, \sigma^2_y)$，则激活后方差：

$$\text{Var}(\text{ReLU}(y)) = \mathbb{E}[y^2 \cdot \mathbf{1}_{y>0}] = \int_0^{+\infty} y^2 \cdot \frac{1}{\sqrt{2\pi}\sigma_y} e^{-y^2/2\sigma^2_y} dy = \frac{\sigma^2_y}{2}$$

前向方差一致条件修正为：

$$n_{\text{in}} \cdot \text{Var}(W) \cdot \frac{\sigma^2_y}{2} = \sigma^2_y \implies \text{Var}(W) = \frac{2}{n_{\text{in}}}$$

正态分布采样：$W \sim \mathcal{N}!\left(0,\ \sqrt{2 / n_{\text{in}}}\right)$

#### 7.4 对比与选型

|初始化方案|推荐激活函数|方差公式|采样分布|
|---|---|---|---|
|Xavier 均匀|Sigmoid / Tanh|$2 / (n_{\text{in}} + n_{\text{out}})$|均匀|
|Xavier 正态|Sigmoid / Tanh|$2 / (n_{\text{in}} + n_{\text{out}})$|正态|
|Kaiming 正态|ReLU / GELU / SiLU|$2 / n_{\text{in}}$|正态|
|Kaiming 均匀|ReLU 变体|$\sqrt{6 / n_{\text{in}}}$ 作为上界|均匀|

激活函数确定后，初始化方案随之确定。现代 LLM 使用 SiLU / GELU，对应 Kaiming 正态初始化。
