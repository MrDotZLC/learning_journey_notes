## 1️⃣ 单头维度 $d_k$ 的选择
### 1.1 理论依据
- 单头输出维度 = $d_k$​ → 决定单头注意力子空间的表示能力
- 点积方差$\text{Var}(QK^\top) \approx d_k$ → softmax 输入标准差 σ ≈ √d_k
- d_k 太小 → 子空间受限，注意力均匀
- d_k 太大 → softmax 易饱和，梯度消失
### 1.2 经验选择

|模型规模|总 hidden dim d|单头维度 d_k|多头数 h = d/d_k|
|---|---|---|---|
|小/中型|512~1024|64~128|8~16|
|大型|4096~20480|128~512|40~160|

- 原则：**保证单头输出子空间足够大，同时多头能覆盖不同子空间**
- 实验表明 d_k ≈ 64~128（小模型）、128~256（大模型） → softmax 稳定
### 1.3 微调策略
- 微调预训练模型 → 通常保持 d_k 不变
- 自建模型 → 根据 d 选择 d_k，h = d / d_k
- 可监控注意力分布：
    - 平坦 → d_k 太小
    - 极端集中 → d_k 太大
## 2️⃣ 多头注意力设计
### 2.1 核心理念
将单个注意力机制拆成多个 **并行头（head）**
每个头有自己的投影矩阵：
$$Q_h = XW_h^Q,\quad K_h = XW_h^K,\quad V_h = XW_h^V$$
多个头并行计算注意力 → 输出拼接或平均 → 形成最终表示
> 目标：**不同头学习不同子空间特征，捕捉多样化依赖关系**
### 2.1 为什么单头不行
#### 1. 单头限制
- 单头注意力：
$$\text{Attention}(Q,K,V) = \text{softmax}\Big(\frac{Q K^\top}{\sqrt{d_k}}\Big)V$$
- 输出维度 = d_k → 单头只能表示一个子空间
- 对复杂序列依赖：
    - 可能存在多种不同类型的关系（如语义、句法、长程依赖）
    - 单头难以同时捕获全部信息
#### 2. 低秩限制
- 单头注意力矩阵往往近似低秩
- 单头 d_k 固定 → 子空间维度受限 → 信息可能丢失
- 多头可以覆盖更多子空间 → 增加表达能力
## 3️⃣ 为什么选择 $\sqrt{d_k}$​​ 作为缩放因子
### 1. 理论依据：
- 点积标准差 σ ≈ √d_k
- 除以 √d_k → softmax 输入标准差 ≈ 1 → 梯度稳定
### 2. 实验验证：
- 不缩放 → 大 d_k 导致梯度消失，训练不稳定
- 缩放 √d_k → 训练收敛快，性能好
### 3. 直觉总结：
- √d_k 缩放控制数值幅度，保证 softmax 平滑又不过平坦
## 4️⃣ 动态缩放因子 α
### 3.1 原理
$$\text{Attention}(Q,K,V) = \text{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}} \cdot \alpha\Big) V$$
- α 可训练或动态生成
- 功能：自适应调整 softmax 温度，控制注意力权重稀疏/平滑
- 不改变单头输出维度 → 不影响子空间表示能力
### 3.2 优势与缺点

|方法|优势|缺点|实践情况|
|---|---|---|---|
|固定 √d_k|简单，训练稳定，硬件友好|无法自适应|主流 Transformer|
|动态 α|自适应 softmax 温度，潜在更稳定|增加计算和参数，训练复杂|少量实验或特定大模型使用|

- 核心结论：**固定 √d_k 是折中方案**，简单且对大多数任务足够好
## 5️⃣ d_k 与 α 的关系

| 参数  | 功能                            | 对特征表达影响                |
| --- | ----------------------------- | ---------------------- |
| d_k | 决定 V 列空间维度 → 单头输出子空间          | 直接影响单头表示能力             |
| α   | 调整 softmax 权重 → 控制 token 聚合方式 | 不改变子空间维度，只影响注意力分布稀疏/平滑 |

## 6️⃣  实操建议（自建大模型示例）
假设 d = 20480，计算能力充足：
1. **选择单头维度 d_k**：
    - 推荐 256~512 → balance 单头能力和多头数量
    - σ ≈ √d_k ≈ 16~22 → softmax 数值稳定
2. **计算多头数 h = d / d_k**：
    - d_k = 256 → h = 80
    - d_k = 512 → h = 40
3. **训练注意事项**：
    - 观察注意力分布，调整 α 或 d_k 微调训练稳定性
    - 可考虑 Q/K 标准化或可训练缩放 α 来进一步稳定训练
## 7️⃣ 总结一句话
> d_k 决定单头表示能力，√d_k 缩放保证 softmax 稳定，α 可训练提高灵活性；固定 √d_k 是工程与理论结合的折中方案，动态 α 可以进一步自适应，但增加复杂性。
