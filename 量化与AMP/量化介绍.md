# 一、量化（Quantization）的本质
量化是一个**有损映射（lossy mapping）**过程：
> **连续空间 / 高精度数值 → 离散空间 / 低比特数值**
 关键是：  
	**如何设计映射规则，使误差最小、效率最高、硬件可执行。**
---
# 二、核心数学概念
量化的核心公式是**仿射变换（Affine Mapping）**。对于一个浮点张量 $x$，其量化过程可以表示为：
 $$x_q = \text{round}\left(\frac{x}{S} + Z\right)$$
 - **$S$ (Scale) 缩放因子：** 决定了量化的步长。
	S 大 → 范围大但精度粗
	S 小 → 精度高但易溢出
- **$Z$ (Zero-point) 零点：** 保证浮点数中的 $0$ 能精确对应到整数空间。
	非对称量化中，浮点数据通常不是对称分布（如ReLU激活），Z 作为**偏移量**避免大量浪费。
- **反量化（Dequantization）：** 计算时还原为 $\hat{x} = S(x_q - Z)$。

# 三、量化方法分类
## 3.1 按时间/阶段分类
### 3.1.1 后训练量化（PTQ, Post-Training Quantization）
#### 定义
- 模型训练完成后再进行量化
- 不改变原始权重，只在推理阶段使用低比特表示
#### 特点
- 快速，不需要重新训练
- 只需少量数据集即可完成数据校准（Calibration），减少误差损失
#### 常用流程
1. 收集校准数据（激活样本）
2. 统计每层激活的分布
3. 选择量化范围（Min-Max、Percentile、KL 截断等）
4. 映射权重和激活到整数
#### 优点
- 快速，工程实现简单
- 芯片兼容性好
#### 缺点
- 精度下降明显，尤其是超低比特（INT4/INT2）
- 对长尾或动态激活敏感
#### 应用
- 轻量模型部署（MobileNet、ResNet-18）
- 初步量化实验
#### 代表算法
- GPTQ 量化
	- 通过 Hessian 二阶近似最小化量化误差
	- 结合权重块感知量化（per-group scale）
	- **应用**：LLM INT4/INT3 权重量化
### 3.1.2 量化感知训练（QAT, Quantization-Aware Training）
#### 定义
- 在训练过程中模拟量化误差，让模型适应低比特表示
#### 核心思想
- 使用 **Fake Quantization** 模拟整数计算：
$$x_q = \text{round}(x / s + z)$$
- 梯度通过 **STE（Straight-Through Estimator）** 近似传递：
$$\frac{\partial \text{round}(x)}{\partial x} \approx 1∂$$
#### 优点
- 精度高，低比特量化可稳定训练
- 对大模型（Transformer、BERT、GPT）适用
#### 缺点
- 训练时间增加
- 需要量化感知训练框架支持
#### 工程实践
- INT8 权重+激活量化
- INT4/INT3 超低比特大模型
#### 应用
- Fake Quantization + STE
	- 模拟量化误差，训练时通过 Straight-Through Estimator 梯度传递
	- **应用**：低比特 INT8 / INT4 训练
- PACT（Parameterized Clipping Activation）
	- 激活截断阈值可学习
	- 对动态激活分布自适应
	- **应用**：ReLU 激活低比特量化
- **LSQ（Learned Step Size Quantization）**
	- 学习 scale（步长）参数
	- 支持权重/激活量化
	- **应用**：INT8/INT4 低比特大模型
- **QDrop / Gradual Quantization**
	- 训练过程中逐步降低比特精度
	- 避免模型精度骤降
	- **应用**：超低比特大模型训练（Transformer）
## 3.2 按数值映射方式分类
量化还可以按**映射规则**划分：对称量化（Symmetric Quantization）和非对称量化（Asymmetric Quantization）。
### 3.2.1 线性量化
#### 3.2.1.1 对称量化（Symmetric Quantization）
##### 定义
- 量化范围关于 0 对称
- 无 zero-point 偏移
$$q = \text{round}(x / s)$$
##### 特点
- 权重量化常用
- 硬件高效，卷积/矩阵乘法容易优化
##### 缺点
- 非对称分布数据表示效率低
#### 3.2.1.2 非对称量化（Asymmetric Quantization）
##### 定义
- 量化范围可非对称
- 通过 zero-point 将浮点 0 对齐到整数
$$q = \text{round}(x / s + z)$$
##### 特点
- 激活量化常用
- 表示范围灵活，适合非对称分布
##### 缺点
- 硬件实现稍复杂
- 累加需要考虑 zero-point
### 3.2.3 非线性量化
映射关系非线性
#### 3.2.3.1 对数量化（Log Quantization）
##### 数学公式
$$q = \text{round}(\text{sign}(x) \cdot \log(|x| + \epsilon) / s)$$
- $\epsilon$ 防止 log(0)
- scale s 映射到整数范围
##### 特点
- 对长尾权重和激活敏感
- 小值精度高，大值压缩
- 适合权重分布跨度大场景
##### 工程应用
- 权重量化 INT4 / INT2
- 超低比特 LLM 权重
##### 优缺点
- 优点：超低比特精度高
- 缺点：硬件复杂，不直接用矩阵乘法
- 应用：超低比特权重量化（INT4 / INT2）
##### 代表算法
- **NF4（Normalized Float 4）**
    - 4-bit 浮点风格
    - 小值精度高，大值压缩
    - LLM 权重量化 INT4
- **LogQuant**
    - 对数映射整数编码
    - 用于长尾分布权重或激活
- **μ-Law / A-Law**
    - 常用于信号处理
    - 对小权重/激活精度高 
#### 3.2.3.2 k-means / 聚类量化（Cluster-Based Quantization）
##### 数学原理
- 将权重或激活向量聚类为 K 个中心（codebook）
- 每个浮点值映射到最接近的中心：
$$q = \arg\min_{c_i \in C} |x - c_i|$$
- 解码时查表还原：
$$\hat{x} = c_q$$
##### 特点
- 可以使用非常低比特（如 2~3 bit）
- 保留分布特征
- 非线性映射，可针对长尾和分布稀疏的权重
##### 工程应用
- 超低比特大模型权重量化
- 适合存储优化场景
##### 代表算法
- **K-Means Quantization**
    - 聚类浮点值到 K 个中心
    - 超低比特（2~3bit）大模型权重
- **Product Quantization（PQ）**
    - 将向量分块聚类
    - 用于大规模向量压缩
#### 3.2.3.3 动态范围分段量化（Piecewise / Segmented Quantization）
##### 数学原理
- 将数值范围分成多段，每段线性量化
$$q = \text{round} \left( \frac{x - x_{\text{seg\_min}}}{s_\text{seg}} \right)$$
- 每段 scale 不同 → 非线性整体映射
##### 特点
- 结合线性和非线性优点
- 对中间值精度高，极端值压缩
- 可动态适应不同分布
##### 工程应用
- 激活量化长尾分布
- 超低比特 Transformer / CNN
##### 代表算法
- Piecewise Linear Quantization
	- 将数值范围分段线性映射
- **Segmented LUT**
    - 查表 + 分段线性映射
    - 可用于超低比特激活量化
#### 3.2.3.4 自适应量化（Adaptive / Learned Quantization）
##### 数学原理
- 量化函数参数可学习：
$$q = \text{round}(\alpha(x) \cdot x + \beta(x))$$
- α、β 可训练或自适应计算
##### 特点
- 非线性映射，可针对权重/激活自动优化
- 精度高，适合低比特 LLM
- 硬件实现复杂，需要查表或微型计算单元
##### 工程应用
- GPTQ / AWQ 的优化思想
- INT3/INT4 超低比特量化
##### **代表算法**
1. **LSQ / LSQ+**
    - 学习步长与零点参数
2. **AWQ（Activation-Wise Quantization）**
    - 考虑激活敏感性优化权重量化
    - INT3/INT4 LLM
#### 3.2.3.5 LUT 查表量化（Lookup Table Quantization）
- 事先生成浮点→整数映射表
- 映射非线性，直接查表
- 优点：高精度、适合低比特
- 缺点：查表占内存、硬件复杂
- 代表算法
1. **Lookup Table Quantization**
    - 预生成浮点→整数表
    - 低比特精度高
2. **Cluster + LUT**
    - 聚类后查表
    - 超低比特存储优化
#### 3.2.3.7 表格对比

|方法|映射特点|优点|缺点|典型应用|
|---|---|---|---|---|
|Log / 对数量化|log 压缩大值|长尾保留小值|硬件复杂|超低比特权重|
|k-means 聚类|离散聚类中心|极低比特、保留分布|查表解码|INT2/INT3 权重|
|μ-Law / A-Law|对数或压缩|小值精度高|工程复杂|音频/神经网络|
|分段量化|分段线性|精度高，兼顾极值|实现复杂|激活量化、长尾分布|
|自适应/学习|可训练参数|精度最优|训练成本高|Transformer/LLM INT3/4|
|LUT 查表|查表非线性|精度高|内存/硬件复杂|超低比特量化|
## 3.3 按粒度分类
量化粒度决定了 scale/zero-point 是共享还是独立：
### 3.3.1 Per-Tensor（张量级）
- 整个张量使用同一个 scale
- 实现简单，存储 overhead 小
- 精度较低，对通道分布差异敏感
- 标准 PTQ INT8 / INT4
### 3.3.2 Per-Channel（通道级）
- 每个卷积/全连接通道独立 scale
- 精度高，尤其适合卷积权重
- 存储 overhead 较大
- Conv/FC 权重量化
- GPTQ / NF4 4-bit LLM 权重
### 3.3.3 Per-Group（组级）
- 张量分组，每组使用独立 scale
- 精度与存储折中
- 常用于大模型权重量化（如 LLaMA 7B, GPTQ）
## 3.4 按量化对象分类
量化对象决定策略和精度控制：
### 3.4.1 权重量化（Weights）
- 权重分布静态、可统计
- 常用 **Per-Channel 对称线性量化**
- INT8 权重是工业标准
#### 优缺点
- 优点：稳定，可提前计算 scale
- 缺点：低比特量化误差累积
#### 工程实践
- 卷积/全连接层权重量化
- Transformer 权重 Per-Group / Per-Channel
- INT8 对称
- NF4 / GPTQ / AWQ 超低比特
### 3.4.2 激活量化（Activations）
- 动态变化，输入不同分布不同
- 常用 **非对称量化 + 截断（Percentile / KL）**
#### 优缺点
- 优点：可降低推理内存和计算量
- 缺点：低比特精度下降明显
- 需要动态/校准数据
#### 工程实践
- Transformer 激活 KL 截断
- ReLU 可用 Percentile
- INT8 / 非对称
- KL 截断 / PACT / LSQ
### 3.4.3 梯度量化（Gradients）
- 用于训练阶段
- 目的是降低通信带宽
- 精度要求低于推理权重/激活
#### 工程实践
- FP32 → FP16 / BF16
- 分布式训练通信优化
- FP32→FP16/BF16
- ZeRO-2/3 通信优化
### 3.4.4 偏置量化（Bias）
- 偏置通常保留高精度（FP32 / INT32）
- 避免累积误差导致输出漂移
- FP32 或 INT32
- 保持累积精度
## 3.5 按数值精度分类
|类型|比特|特点|应用|
|---|---|---|---|
|FP16 / BF16|16|半精度浮点，训练加速|GPU训练、混合精度|
|INT8|8|推理主流|移动端 / Edge AI|
|INT4 / INT2|4/2|超低比特|大模型压缩|
|FP8|8|新兴浮点格式|高性能训练 / Transformer|
## 3.6 特殊方法（大模型量化）
- **GPTQ**：Post-training LLM 量化，Hessian 最小二乘
- **AWQ**：考虑激活敏感性，优化权重量化
- **SmoothQuant**：将激活峰值平滑到权重，减少 Transformer 激活爆炸

# 四、截断（Clipping）
在神经网络中，激活或权重可能有极端值：
- 激活：ReLU 输出可能出现非常大的数值
- 权重：训练过程中可能存在 outlier
- 直接映射到 INT8 或 INT4 时，这些极端值会拉大 scale，降低整体精度

**直观理解**：如果一两个大值决定了整个 scale，其他 99% 的值可能只能用很粗的整数表示。
## 4.1 截断方法
### 4.1.1 Min-Max 截断
- 使用张量的最小值和最大值作为量化范围
- 简单，但极端值会影响整体精度
$$x_{min} = \min(x) , \quad x_{max} = \max(x)$$
### 4.1.2 Percentile 截断
- 忽略极少数异常值
- 常用 99% 或 99.9% percentile
- 更稳定，保留大部分分布信息

$$x_{min} = \text{Percentile}(x, 0.1\%), \quad x_{max} = \text{Percentile}(x, 99.9\%)$$
### 4.1.3 KL 散度截断
KL 散度截断是**后训练量化（PTQ, Post-Training Quantization）** 中的一种高级截断方法，通过最小化原始数据分布与量化后数据分布的差异，确定激活或权重的截断范围。
#### 4.1.3.1 背景
在激活量化中：
- 激活值分布通常呈 **长尾** 或 **非对称分布**
- 直接使用 **Min-Max 截断** 会被极端值拉大 scale，导致大部分常用值表示精度下降
- Percentile 截断忽略极端值，但无法保证量化后信息损失最小
#### 4.1.3.2 KL 散度定义
KL 散度提供了一种**概率分布差异的衡量方法**，用于寻找最优截断阈值。
KL 散度衡量两个概率分布 P 和 Q 的差异：
$$D_{KL}(P || Q) = \sum_i P(i) \log \frac{P(i)}{Q(i)}$$
- P：原始浮点值的概率分布（通常通过直方图估计）
- Q：量化后的概率分布（量化到有限整数表示后再重建概率分布）
> KL 散度越小，表示量化后分布越接近原始分布，信息损失越小。
#### 4.1.3.3 KL 截断算法流程（以激活为例）
假设我们量化到 INT8（256 bins），流程如下：
- Step 1：统计原始分布
	- 将浮点激活值放入直方图，得到概率分布 P
	- 直方图 bin 数较大（例如 2048 bins）
- Step 2：选择候选截断阈值
	- 从小到大遍历不同的最大值 xmaxx_{max}xmax​
	- 将极端值截断到 xmaxx_{max}xmax​
- Step 3：模拟量化
	- 将截断后的范围映射到 INT8 的整数范围（0~255）
	- 将整数映射回浮点，得到量化后的分布 QQQ
- Step 4：计算 KL 散度
$$D_{KL}(P||Q) = \sum_{i} P(i) \log \frac{P(i)}{Q(i)}$$
- Step 5：选择最优阈值
	- 选择使 $D_{KL}(P||Q)$ 最小的 $x_{max}$
	- 该阈值即为量化截断点
> 	如果激活是非对称分布，还可以同时搜索 $x_{min}$​（下限）。
#### 4.1.3.4 数学直观理解
KL 散度截断本质是在解决一个优化问题：
$$x_{max}^* = \arg\min_{x_{max}} D_{KL}(P_{clip(x_{max})} || Q_{quantized(x_{max})})$$
- $P_{clip(x_{max})}$：截断后的原始分布
- $Q_{quantized(x_{max})}$：量化重建分布
> 核心目标：选择截断阈值，使量化后信息损失最小化，而不仅仅是覆盖全量程或去除极端值。
#### 4.1.3.5 工程实践
- **优点**：
    - 自动找到最佳截断阈值
    - 对非对称、长尾激活分布效果好
    - PTQ 中精度通常高于 Min-Max / Percentile
- **缺点**：
    - 计算复杂（需要多次直方图量化和 KL 计算）
    - 适合静态量化（校准数据集有限）
    - 对极低比特（INT4）可能仍需结合其他方法
- **应用场景**：
    - Transformer 激活量化
    - ResNet、MobileNet 后训练量化
    - 大模型 PTQ（如 LLM 激活量化）

# 五、舍入（Rounding）
量化过程中，有 Round 过程，使得反量化存在舍入误差。
## 5.1 常见舍入方法
### 5.1.1 Round-to-nearest（四舍五入）
- 误差范围 [−0.5s,+0.5s]
- 优点：简单、硬件易实现
- 缺点：累积误差在深层网络中可能偏移输出
### 5.1.2 Stochastic Rounding（随机舍入）
- 根据浮点数与上下邻近整数的距离，以概率选择舍入方向：
$$q = \begin{cases} \lfloor x \rfloor, & p = 1 - (x - \lfloor x \rfloor) \\ \lceil x \rceil, & p = x - \lfloor x \rfloor \end{cases}$$
- 优点：
    - 可以降低量化偏置
    - 对低比特量化（INT4 / INT2）尤其有效
- 缺点：
    - 实现复杂，需要随机数生成
### 5.1.3 Floor / Ceil
- Floor：向下取整 → 系统性偏小
- Ceil：向上取整 → 系统性偏大
- 通常在特定硬件或量化要求中使用，但容易产生偏差
## 5.2 工程实践
1. **权重量化**
    - 权重分布相对稳定，累积误差可控
    - 常用 **Round-to-nearest**
2. **激活量化**
    - 分布动态且非对称
    - 可以使用 **Stochastic Rounding 舍入**降低偏置
3. **低比特量化**
    - INT4 / INT2 中 Round-to-nearest 会导致严重误差
    - **Stochastic 舍入** 能显著提升稳定性
4. **硬件实现**
    - 大部分 GPU/CPU INT8 计算使用 Round-to-nearest
    - **Stochastic 舍入** 在软件模拟或定制硬件中实现

# 六、量化误差（Quantization Error）
量化不可避免会引入误差，通常可分为四类：
## 6.1 舍入误差（Rounding Error）
### 来源
- 浮点数映射到离散整数时，需要舍入：
$$q = \text{round}(x/s + z)$$
 - 例如 FP32 → INT8 时，每个浮点数只能选择最接近的整数表示。
 ### 特性
 - 均值通常接近 0，但可能累积
 - 对低比特量化（INT4/INT2）影响大
 - 在深层网络中可能导致输出偏移
 ### 解决方法
 - 使用 **stochastic rounding**（随机舍入）降低偏置
 - 使用 **higher bit scale** 做累积
## 6.2 截断误差（Clipping Error）
### 来源
 - 当数据超出量化表示范围时，必须截断：
$$x_{clip} = \text{clip}(x, x_{\min}, x_{\max})$$
 - 典型场景：激活值或权重中存在异常大值（outlier）
### 特性
 - 错误集中在极端值上
 - 损失信息，但对整体精度影响可控
 - 对非对称分布数据敏感
### 解决方法
 - **Percentile Clipping**：忽略极少数异常值
 - **KL Divergence 方法**：选择截断阈值最小化信息损失
## 6.3 累积误差（Accumulation Error）
### 来源
 - 在深层网络中，每层量化误差会向后传播
 - 矩阵乘法或卷积中累加多个量化值时，误差叠加：
$$ \epsilon_{total} = \sum_i \epsilon_i$$
### 特性
 - 深层网络容易出现激活漂移（activation drift）
 - Transformer 或 ResNet 等深网络尤其敏感
 - 对最终输出 logits 可能产生显著偏移
### 解决方法
 - 保留 **bias 或累加结果为高精度（INT32 / FP32）**
 - 使用 **per-channel 量化** 减少误差差异
 - 激活校准（activation calibration）在部署时校正
## 6.4 偏置误差（Bias Error / Distribution Shift）
### 来源
 - 数据分布或量化零点选择不当
 - 非对称量化中 zero-point 不匹配
 - 激活分布与训练数据分布不同（测试时 shift）
### 特性
 - 导致量化后输出系统性偏移
 - 对精度敏感层（如 Softmax / LayerNorm）影响大
 - 不是随机噪声，而是偏向一侧
### 解决方法
 - 使用 **非对称量化**，调整 zero-point
 - 激活范围动态调整（动态量化 / calibration）
 - 对关键层保持高精度

# 七、主流量化技术
主流的大模型量化技术可以根据其**应用场景**、**位宽**以及**对硬件的优化方式**分为以下几个核心阵营。这些技术是目前工业界和开源社区最常使用的方案：
## 7.1 推理部署主流：GPTQ 与 AWQ
这两者是当前 GPU 部署（如 vLLM, TensorRT-LLM）最常见的 4-bit 量化方案，主要解决**显存带宽**瓶颈。
### 7.1.1 **GPTQ (Generative Pre-trained Transformer Quantization)**
[GPTQ 深度解析](GPTQ%20深度解析.md)
- **原理**：基于二阶信息（Hessian矩阵）的补偿技术。它逐层扫描模型权重，当一个参数被量化产生误差时，它会调整该层中尚未量化的剩余权重来“抵消”这个误差。
- **特点**：量化速度快（几小时内完成 70B 模型），在超大模型上精度保持极好。
- **适用**：云端大规模推理，生产级部署。
### 7.1.2 **AWQ (Activation-aware Weight Quantization)**
- **原理**：它发现并不是所有权重都同等重要。AWQ 通过观察校准数据的激活值分布，识别出那些对精度贡献最大的“显著权重”（通常占比 1%），然后对这些权重进行缩放保护，不进行激进量化。
- **特点**：相比 GPTQ，它不依赖复杂的误差补偿，对模型泛化能力（如指令遵循、多模态）保护更好。
- **适用**：目前 vLLM 等高性能推理框架的首选。
## 7.2 个人微调主流：bitsandbytes (QLoRA)
这技术彻底改变了个人开发者在普通显卡上训练大模型的现状。
- **NF4 (NormalFloat 4)**
    - **原理**：假设权重服从正态分布，将 4-bit 的 16个量化槽位按照正态分布的概率密度进行非均匀分布。
    - **特点**：在 4-bit 下达到了惊人的精度。配合 **QLoRA** 技术，它允许用户在 24GB 显存的显卡（如 3090/4090）上微调 70B 模型。
    - **适用**：低成本模型训练与微调、Hugging Face 快速加载模型预览。
## 7.3 本地/端侧主流：GGUF (llama.cpp)
如果你是在苹果 Mac (M1/M2/M3) 或 普通电脑 CPU 上跑模型，这是绝对的主流。
- **GGUF / K-Quants**
    - **原理**：采用分块量化（Block-wise Quantization），支持极其灵活的混合精度（例如：权重的一部分用 4-bit，关键部分用 5-bit，次要部分用 2-bit）。
    - **特点**：单一文件格式，兼容性极强，支持 CPU/GPU 混合推理，显存不足时可以将部分层“卸载”到系统内存。
    - **适用**：本地部署、Mac 用户、端侧设备。
## 7.4 高吞吐加速主流：SmoothQuant
前述方案大多是“仅权重量化”，而 SmoothQuant 致力于“全量化”（W8A8），以激活硬件的整数算力。
- **SmoothQuant (W8A8)**
    - **原理**：解决激活值中的“离群点”（Outliers）问题。它通过数学等式变换，将激活值的量化难度平滑地转移到权重上。
    - **特点**：能够调用 NVIDIA Tensor Cores 的 **INT8 算力**，实现推理速度的成倍提升（不仅是省显存，而且算得更快）。
    - **适用**：高并发、低延迟的商业 API 服务。
## 7.5 硬件原生标准：FP8
这是随着 NVIDIA H100 等新一代显卡普及而出现的新主流。
- **FP8 (8-bit Floating Point)**
    - **原理**：不再使用整数映射，直接使用 8 位浮点格式（E4M3 或 E5M2）。
    - **特点**：硬件原生支持，精度几乎等同于 FP16。它不需要复杂的校准（PTQ）过程，只需在支持 FP8 的算力卡上直接加载即可。
    - **适用**：H100/B200 等高端算力集群，未来两年的行业标准。
